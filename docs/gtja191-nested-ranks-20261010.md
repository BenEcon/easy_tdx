## 数值与缺失边界

- 只对**已知平均百分位排名**重建有界分母分数；不对原始价格做近似分数化。截面界为 2×当日池大小，时序界为 2×窗口长度。
- 140 的四排名加减保持真实相等；157 的排名窗口和避免 `.2+.4+.6` 与 `.4+.4+.4` 因舍入差异拆开并列。119／138 的时序排名加权使用正确时序分母界，旧函数默认界不变。
- 原始缺失、非法 OHLC、无穷、负值、零分母及相关常数保持缺失。两路依赖必须都完整；即使幂的底数为 1，也不能绕过缺失指数。
- 四个新 VWAP 公式仍仅允许经量额／价格范围核验的 NONE 输入。没有静默换复权、代理均价或缩小股票池。
