# 因子任务真实进度与历史结果取回 · 2026-10-10

本批仅本地实现与验收，不是因子体系总目标完成声明，未部署生产。

## 已实现

- 共享任务结果增加 `kind` 和 `progress`。因子值按标的、截面检验按远期窗口、冗余按因子对、时间划分按窗口、冻结输入按标的、完整结果校验按一次校验发布实际处理量。每次执行独立递增序号。
- 显示的是**当前阶段的处理量**，不是总体百分比、预计剩余时间或断点续算位置。即使校验阶段为 1/1，仍以工作进程退出及服务端发布的终态判断完成，不能显示部分结果为成功。
- 内存与独立持久 worker 都支持进度。持久写入校验账户所属任务的执行租约、代次、令牌、状态与单调序号；过期执行者不能回写。取消后不再发布新单位，重新排队清空旧进度，从冻结输入重新计算。
- 进度存储故障明确失败，不能被逐因子容错吞掉后呈现成功；计算数值和原始研究存档不加入瞬态进度字段。前后端严格检查类型、范围及 Unicode 字符数，避免字符串强制转换放过非法阶段。
- 个人账户 → 后台计算 → 已完成因子检验 → 打开因子结果。读取原任务完整结果，不查当前因子目录、不重新取行情、不自动计算；可查看所有远期窗口，导出完整研究或保存为个人云存档。
- 任务清理与研究存档独立；需主动保存原研究才能在清理任务后继续查看。读取绑定当前账户与任务编号，切换账户、任务或关闭界面立即使旧响应失效。
- 结果对比页不再将因子分层研究作为交易回测记录列入比较。页面沿用暗色、轻分隔和已有表格／图表组件；手机只在表格内部横向滚动。
- WebKit 实测修正嵌套弹窗关闭的焦点问题：子弹窗卸载后，再恢复“打开因子结果”按钮焦点，且不抢占新任务／账户的焦点。
