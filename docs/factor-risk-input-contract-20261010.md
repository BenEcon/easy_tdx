# GTJA030 风险三因子输入契约（本地，第三十五批 A）

## 状态与边界

已实现来源、单位、日期及可得性契约，并接入现有冻结输入、股票池检验和只读存档校验。不是 GTJA030 公式交付或网页可用声明。没有采购数据、调用收费服务、上传用户数据、修改缠论或部署服务器。

GTJA030 仍待独立滚动回归内核、合格风险数据来源、统一目录／页面／任务接入及端到端验收。本批不增加登记、实现、可用、验收通过或已部署因子数量。既有统计保持 GTJA190；全库登记368、去重定义367、已实现365。具体数据就绪和页面条件统计仍以第三十四批冻结证据为准，不能推及 GTJA030。

## 数据 API 与语义

新增 `easy_tdx.factor.risk_inputs`：

1. `freeze_risk_tape(metadata, rows)`：复制并冻结1–800条原始风险数据，SHA256摘要。
2. `attach_risk_inputs(frame, tape)`：返回新的行情副本，不覆盖已有风险输入，不改变原数据。
3. `validate_risk_inputs(frame)`：无取数、无因子执行地逐值核对完整源快照、可得性及对齐列。
4. `validate_risk_pool(frames)`：一个池共用同一版本源快照；拒绝不同来源修订或只有部分标的附带数据。

元数据必须声明 dataset_id、provider、source、methodology、universe、licence、vintage_at，以及固定版本、CN_A市场、DAY频率、decimal_return单位、market_excess_return的MKT语义。后一个是本契约明确的 FF3 输入解释，不宣称原研报指定了唯一供应商或构建方法；供应商构建方法和范围必须记录。声明许可仅用于追溯，不是自动判定已经获得法律授权。

每条记录包含 `date`、`available_at`、`mkt`、`smb`、`hml`。日期采用YYYY-MM-DD；available_at及版本时间必须带时区。缺失值使用null；正、负、零均有意义，拒绝布尔、字符串、无穷数及未声明单位转换。

原始日期不得重复或乱序，不能将同一观测日的多个修订静默合并。可得时间不得早于该日收盘或晚于版本时间。不同历史发布版本应保存为不同数据包，不覆盖原研究快照。

## 日期对齐和因果限制

当前契约只支持明确已收盘的A股日线；日标签或15:00收盘标签被明确映射为上海时区同一交易日15:00。其他时间标签、分钟周期和未知复权一律拒绝，不重采样或借相邻日填空。

逐行状态包括：

- `ready`：该日三个值均完整，且在当日收盘时已可得。
- `missing_date`：源数据没有同日记录。
- `missing_value`：源数据至少一项为空，整组三项不作为完整回归输入。
- `not_available_at_close`：同日因子发布晚于当日收盘；原值保留在源快照，对齐计算列留空。

**尚未实现延迟发布数据的事后解释模式和因子实际发布时间传播。**不能把后发布的值移到前一天，也不能将其平移一天后仍称为原式同日回归。后续若要利用真实供应商普遍存在的发布延迟，应同时输出实际可得时间，并将事后解释与可交易预测研究分开验收；本批严格入口不会假装解决这一余项。没有真实风险三因子数据时，不声称GTJA030已开箱即用。

## 冻结与兼容

沿用 `factor-input-v1` 的可扩展 attrs 保存 `factor_risk_inputs`，包括源数据、逐行状态、对齐策略和版本。不建立另一套研究存档；旧无风险输入快照不要求补充字段，不触发外部请求。复算前后的摘要、元数据及逐行值保持一致。即使重新计算外层摘要，伪造已对齐值或可得性也会被拒绝。

合成数据均标为测试用途。三复权真实个股冻结行情只证明原行情的兼容性；搭配的风险三因子依然是合成测试数据，不能声称通过真实 FF3 行情验收。
