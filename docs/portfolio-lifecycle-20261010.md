# 组合与异步任务生命周期验收 · 2026-10-10

## 本地实现

- `task-execution.ts` 共用组合、多策略、单策略寻优、全策略寻优的前端任务连接。提交时复制完整请求、绑定账户与代际；清理只停止本地等待，不取消服务器任务。返回编号、状态和结果形状需匹配，不将取消中或无有效结果当完成。
- 各槽位保存相互对应的结果与请求快照。换账户清除旧槽位；过期失败不得覆盖新任务的错误或运行状态。提交是主动查询，状态轮询不是主动查询。
- API 可带 `X-Task-Owner`；服务器以真实 Cookie 账户核验，不一致返回 409。错误归属的请求也不写入新账户查询统计。旧客户端仍兼容，标记不是授权凭据。
- 策略库通过保存 ID 打开组合页，恢复股票、策略参数、日期、周期、复权、资金和全部成本。载入不自动回测。非法股票身份、重复成员、非组合记录等明确拒绝；旧缺项列出回退说明。
- 组合页显示最低佣金、印花税等成本；保存使用实际完成请求，不读取后来编辑的表单。改参数、账户或离页使旧任务结果失效；说明后台任务未取消。
- 策略库创建/查询/保存/删除绑定账户和请求代际；名称查询期间的旧输入不混入新模板。多策略保存使用实际任务请求；寻优取行情前捕获参数，查看结果按原请求的策略、标的、周期和复权跳转。

这些改动不修改缠论、策略信号、撮合、成本计算或复权算法。

## 必须继续的边界

1. 多策略“重跑到今天”及将多个单策略合并时，仍采用当前统一复权/成本等口径；必须完善保存上下文选择、差异提示及端到端验收，不能宣称已原样恢复所有已存组合。
2. 寻优结果跳转还未完整携带资金/成本/成交方式，原行情和执行版本精确复现尚未完成。
3. 保存记录在等待策略目录加载的早期，用户编辑与初始化默认参数之间仍有需进一步核验的窗口；后续记录读取阶段已有输入代际保护。不得宣称全部初始化竞态完成。
4. 任务超时依赖实际 fetch 遵循 AbortSignal；不遵守信号且永不返回的自定义 transport 未提供独立 Promise 终止保障。
5. 全站完整市场/板块→雷达→分析→回测→保存流程、其余原十阶段、真机及生产验收继续保留；本节不是总体完成或可直接发布的证明。
