# 单标的策略载入与再保存一致性

## 本地完成的范围

- 策略库单标的“载入”只携带保存 ID，由目标页重新读取当前用户的实际记录。拒绝把 ID 与其他策略、雷达、自动运行或替代行情参数混用。
- 恢复标的市场、周期、复权、日期、策略参数和完整交易成本；新增最低佣金、印花税控件，不再在保存时写回固定默认值。明确矛盾的市场、不可用策略、非法已保存字段拒绝载入，不静默改值。
- 老记录缺失字段采用页面当前设置并逐项说明；这不是对旧成绩的精确复现。载入不自动取数或计算，未载入成功时禁止运行；用户仍可在有效载入后修改配置再算。
- 参数变化清理旧成绩；取行情期间参数变化不再提交旧请求。载入、保存的路由/账户/卸载代际保护避免迟到结果写回新页面；保存防重复点击。
- 新单标的载入、保存、修改请求携带预期账户，后端与实际 Cookie 账户不同返回 409。身份仍由 Cookie 验证，头部不授予权限。旧客户端不带头的调用继续兼容，**不是所有调用者都已经具备预期账户保护**。
- frontend-skill 应用于紧凑费用控件、轻量状态条、缺项列表和手机换行；没有改变全站主题或增加装饰性卡片。
