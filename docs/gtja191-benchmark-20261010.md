# GTJA075／182 · 独立基准指数（2026-10-10，本地）

## 实现与来源

在第三十二批 A 的独立指数契约上，实际实现075、182，统一进入现有目录、参数、单股序列、股票池研究、后台任务、完整导出、账户原档和显式重算。实现版本 `gtja191-complete-window-v13`。没有部署生产，没有修改缠论识别规则。

核对2017-06-15原始研报第13、17页；原PDF SHA-256为 `863f62c2e23bd87ddb42b8338c8fe2b0276d94260ac985e1a0edfff318693c6c`。沿用既有来源许可审计，DolphinDB Apache-2.0 固定提交 `43ace2cc4b81d048864ec2e40c25728d5d464e05` 仅作对照，独立编写计算。没有复制 BenEcon 受限代码，也不重新分发或改许可原研报。

- 075：窗口内“个股收盘高于开盘且基准收盘低于开盘”的次数，除以基准下跌次数；默认50根。零分母留空。
- 182：窗口内“个股和基准同时上涨或同时下跌”的次数除以窗口；默认20根。平盘不计同向。
- 均用严格价格比较、完整有效窗口；缺失及无效价格不变成假平盘，分钟线窗口明确为观测K线根数。不是交易建议，不自动反转方向。

选择依赖指数的因子后才显示“基准指数”，支持上证、深成、沪深300、创业板；指数独立取数、不复权，个股保持自身选定复权。仅精确观测时间对齐，不填充缺失日期、不缩小股票池。辅助取数失败明确记录两项字段原因，只阻断依赖因子，不隐藏其他因子结果；辅助查询不另发用户主动查询请求。

同一股票池只取一次指数。后端、只读导入及显式重算进一步要求所有成功附加基准的标的使用同一原始快照摘要，拒绝同名指数混入不同版本；个股自身不同交易日仍保留。失败来源须显式记录，不能以缺快照冒充成功。此检查建立内部一致性，不把用户上传的数据当成已认证行情。

## 使用与恢复
