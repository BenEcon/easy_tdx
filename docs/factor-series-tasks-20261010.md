# 单股因子序列接入共享后台任务 · 2026-10-10

本批完成本地实现和定向验收，不表示完整因子目标完成，也未部署生产。

## 实际变更

- 新增 `/research/factors/compute/async`，保留原同步接口。提交前冻结已收盘行情、实际复权、量额资格、标的、周期与全部参数，执行时不联网补数。空数据、错误质量、复权不匹配和超过请求范围均明确拒绝，不换复权、不截断。
- `factor_series` 复用内存执行器及持久 worker；冻结载荷往返、源码版本、身份、同账户缓存、配额、取消和完整结果 16 MiB 限制均沿用共享控制面。没有新增数据库版本，仍为 schema 8。
- 每处理一个因子发布真实进度，包含显式的不可用诊断；随后发布输入冻结和完整结果校验进度。处理量不是成功因子数量，更不是总体完成比例。进度持久化失败不能被吞成普通因子错误。未最终完成不得发布部分结果。
- 页面采用任务提交／轮询，区分取消后台与停止等待。输入、参数、账户、页签或离开页面使旧结果失效。个人账户可打开序列任务的完整只读结果，保存到云存档、导出及只读重开；不再被当成交易回测结果。
- 共享前端任务执行器支持显式请求来源；自动初始化为 `system`，主动计算为 `user`，轮询不记入查询。取消仍是任务管理，不是行情查询。
- 修复迟到的因子目录：离开页面后不再发布目录或启动计算；切换输入／账户／页签或手动运行后，目录仍可用于展示，但不再启动挂载时的默认计算。目录加载失败不会默默启动计算。

未改变因子公式、统计口径、MyTT、缠论或原存档数值。

## 使用与页面取舍

量化研究 → 因子序列，选择标的、周期、参数后计算。取得编号后可取消；“停止等待”只解除页面等待，后台任务须到个人账户确认状态。只有完整结果可保存或导出。

沿用 frontend-skill 的应用页面克制原则：原暗色工作区、轻分隔、紧凑状态行和现有组件；配置 → 状态与控制 → 结果／存档，不增加仪表盘卡片。状态更新和输入失效是必要交互，无装饰动画。

持久模式需配套独立 worker；内存模式不具备重启保留能力。没有自动启用生产服务。
