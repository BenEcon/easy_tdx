# 因子研究原档 · 本地验收 2026-10-10

## 操作

1. 在“量化研究 → 因子序列／因子检验”完成计算。
2. “导出完整研究”下载 JSON；“账户云存档 → 保存当前结果到云端”使用现有账户隔离存档服务。
3. “查看原档”展示冻结曲线、数值、公式、实际参数、输入及失败项，不访问当前因子目录或行情，不计算指标。序列支持全屏和原始精度。
4. 如需复算，展开“按原始输入显式重算”，确认使用原输入与当前实现，再点击“开始重算”。检查结果后点击“保存为新版本”。原档不覆盖，新版本记录父档 ID、摘要、修订及旧公式定义。
5. 完整 JSON 可经现有“导入研究备份”导入为独立副本；名称相同不会覆盖旧档。未确认的保存可按同一 ID 重试，避免网络未知结果造成重复创建。

没有完整结果时保存／导出不可用，但仍可打开云目录查看旧档。输入、账户或标签切换清理旧计算结果；账户切换或离开页面清理未完成重算并丢弃迟到响应。同账户资料刷新不清空重算结果。

## 保存内容与校验边界

- `factor-research-v1`：模式、标题、时间、完整原计算响应；包括股票池、周期、复权、实际输入范围、参数、公式来源／版本／摘要、结果、诊断、失败原因、原精度数据。
- `factor-input-v1`：逐标的完整输入列、行、dtype、原索引、行情元数据、量额核验合同及输入错误。NaN、Inf、负零、大整数、时间值显式编码；不把缺失与零混为一谈。不使用 pickle 或可执行序列化。
- 单标的最多 800 根、池最多 20 个标的；不按上限静默截断。复用单档 25MiB、每账户 100 份／128MiB、实例配额、回收站、版本冲突与配对备份体系。
- 服务端核验输入摘要、列／行／索引、参数与公式一致性、周期／复权／标的对应、成功与失败列表完整性。结构验证不调用因子算法，也不依赖当前目录仍保留旧定义。
- 摘要检查只能发现意外变动，不是数字签名。所有上传／导入原档仍明确标记 `client_archive_not_server_verified`，不声称行情、核验合同或因子结果已由服务器重新证明真实。
- 显式重算通过会话身份和 `X-Research-Owner` 双重账户一致性检查，从本人有效存档取数据；不接受调用者指定其他账户，不取新行情。使用冻结的完整实际参数，不用新默认值补齐或忽略未知历史配置。当前实现不支持原配置时明确失败，原档仍可只读。
- 重算复用 compute 资源准入、线程容量与超时控制。取消是取消等待，不宣称服务端工作一定即时停止。新结果保存是独立的显式操作；部分因子失败仍保留，不标成全部成功。
- 重算只是当前实现对冻结输入的计算，不随档附带旧算法运行环境，也不重新认证原始市场来源。计算版本、参数和旧版本依据随新档保存。
- 自动计算、读取／保存／导出／导入、内部快照处理不计入主动查询。只有显式重算提交 `X-Query-Origin: user`；新活动类别为“因子存档显式重算”，仅记录来源存档标识，不记录原始数组。
