# 存档重算：事件对照（本地，未部署）

## 范围

在显式重算结果中增加独立“按事件对照”。不修改原档，不改变严格成笔、MACD、递归或确认算法，不增加行情请求；已有完整字段路径对照仍保留。重算导出记录增加 `events` / `archive-events-v1`，包含覆盖范围、警告、统计、两侧原始位置/值和完整精度差异。

- 覆盖 `bcs` 背离／背驰、`mmds` 结构买卖点、`wave_diagnostics` 候选及未生成候选时的核验记录。
- 分开显示新增记录、本次未再出现、内容变化、一致、无法可靠配对。内容变化另分状态、确认/失效时间、依据/其他字段，可以同时属于多类。
- 标准、非标准、特殊波段、局部双线及结构背驰不相互替代。派生 M1 不重复计为独立识别依据。
- 尚不对递归高层结构及多周期研究结果实施语义配对，它们继续保留完整原始字段对照，不声称全结果已完成语义比较。

## 身份与不确定性

仅相同 `code` / `frequency` 的图表结果可配对；调用方使用同一保存行情重算。此工具不是跨行情窗口事件匹配器。

1. 背离/背驰按类型、方向、当前极值日期、参照极值日期；波段额外使用原始 A 起点（无此字段时用 A 起点）、B 起点、适用的 C 起点。有效 A 裁剪起点变化保留为依据差异，不能替代原始 A 身份。
2. 买卖点按类别、来源和日期；来源缺失不默认为当前工程规则。
3. 核验按族、方向和 C 起点，特殊类用 B 起点。未生成候选可能没有 A 或参照点，因此不以“已有完整 ABC”为配对前提。
4. 确认日、失效日、数组位置、线段整数索引不作身份。时间只规范等价的 T/空格、缺省零秒和尾零，不截掉分钟、不借浏览器时区转换、不以毫秒舍入合并微秒点；日级和日内时间不猜测等价。
5. 缺少身份、未知类型、同键多条均保留原记录，显示无法可靠配对。同集合存在身份不明记录时，不把未匹配的另一侧强称新增/消失；仍可比较两侧身份完整的唯一匹配项。
6. 缺失/无效集合不当作空列表。若两侧明确保存空列表，则允许正常判断增删。统计按身份组计数，重复组内原记录全部保留。

证据集合（checks、comparisons、related_events、events、rejections、gates）只忽略排列顺序，保留重复及所有字段。价格/线段等其他数组仍按顺序比较。证据展开内的字段路径基于规范化集合，原始记录与位置另附；完整原始字段对照仍能看到纯顺序差异。新增和消失不自动转成交易机会或失效标签，也不暗示事后确认在当时已知。

## 页面

使用 frontend-skill 的低装饰分层：统计筛选 → 日期身份清单 → 按需展开证据。默认只看差异及待核验，每页 30 组；可按族筛选、查看一致项、翻页与导出。窄屏只在证据表内横向滚动，保留键盘焦点和原生展开交互，减少动态偏好下关闭过渡。

首轮实际截图发现“范围/显示”标签被挤成两行，已增加不收缩标签，并复用站内 MacSelect 下拉组件，重新构建与浏览器复验。补充触控高度和 320px 弹出菜单边界检查。不是只依据页面总宽度无溢出就宣称布局通过。
