# GTJA 多阶段量价公式 · 第二十八批（本地）

本批新增 025、033、039、044、056、073、074、077、101、123、125、130、141。实现版本 `gtja191-complete-window-v9`，复用现有目录、中文命名参数、单股／整池引擎、后台任务、研究报告与完整原档。不改缠论规则，不部署生产。

## 公式与边界

| 编号 | 关键运算 | 默认完整预热 | 执行范围 |
| --- | --- | ---: | --- |

| 033 | 低点迁移 × 长短收益差排名 × 量时序排名 | 241 | 整池 |
| 039 | 累计均量混合价格相关与差分的加权排名差 | 240 | 整池 |
| 044 | 低价量相关、均价变化两路线性加权时序排名 | 27 | 单股时序 |
| 056 | 开盘相对低点排名与累计量价相关排名比较 | 70 | 整池 |
| 073 | 两层加权相关时序排名与均价均量相关排名差 | 35 | 整池 |
| 074 | 累计混合价格量相关及量价截面排名相关 | 65 | 整池 |
| 077 | 中价均价偏离、均量相关的较小加权排名 | 47 | 整池 |

| 123 | 累计中价均量相关与低价量相关比较 | 87 | 整池 |

| 130 | 中价均量相关与均价量排名相关的加权排名比 | 57 | 整池 |
| 141 | 高价、均量截面排名相关的反向排名 | 23 | 整池 |

所有窗口计当前 K 线观测根数，不自动转换交易日；多层预热依据完整依赖路径取最大值，修改参数同步修改预热。033 强制 long > short。044 遇不同股票缺日仍按本股真实观测记录计时序窗口；其他十二个使用明确股票池的合并日期矩阵，不用时序排名代替截面排名、不补缺日。

来源沿用已核对的原始研报（PDF 第 11—15 页），SHA256 `863f62c2e23bd87ddb42b8338c8fe2b0276d94260ac985e1a0edfff318693c6c`。辅助核对 DolphinDB 官方 Apache-2.0 模块固定提交 `43ace2cc4b81d048864ec2e40c25728d5d464e05`，源码 SHA256 `e3d93adcdacff263795b8f0b97de1b806ce3666b118f7819af59d9ef5ff98543`。不复制 BenEcon 的受限实现。

033 特别按研报的 `(sum_long(RET) − sum_short(RET)) / (long − short)` 括号处理，非辅助参考代码的仅短和除以 220。内核等价抵消重叠的近端收益，避免两个大而接近的和相减；仍要求完整长窗口。独立预期值直接按原括号计算；另有四根手算反例，错误括号会反转股票排名。077 原式两侧的 +HIGH 相消，不新增多余高价项。

线性衰减从旧到新权重 1…w，使用已有补偿求和；已知截面排名的相关保持精确分数并列口径。比较公式只有双方有限才产生 0/1 或 0/−1；常数相关、零分母保持缺失。VWAP 公式继续只允许有明确量额单位与原始价格范围核验的 NONE 输入，拒绝默换复权或代理。没有放松旧公式的数据门槛。
