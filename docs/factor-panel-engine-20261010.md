# 因子整池执行与来源依赖复核（本地）

## 本批实际变更

`PanelFactor` 继承原 `Factor`，复用同一注册表、参数解析、目录和任务／存档入口；没有另设因子平台。`FactorEngine.compute_matrix` 同时调度原时序因子和整池因子，现有截面研究报告改用该入口。此次不注册示例因子，不把基础设施数量计入公式数量。

- 整池因子只执行一次，输入为字段 → 精确观测时间 × 明确标的的矩阵；不能走单股 `compute`。
- 观测时间并集，保留缺失格，不补齐行情、不按行号拼接、不截掉无行情标的；重复／倒序／无时间、字段缺失、已声明的单位错误直接拒绝。已声明复权／周期不一致或只覆盖部分股票也拒绝。
- 观测时间可为分钟、日线、明确 YYYYMMDD 或带时区的时间；时区统一为上海当地时间。截面长表在新面板路径保留 `datetime`，避免同日分钟混淆；该路径的 latest 使用同一个最新时点，不拼接各股不同日期的旧值。
- 原有纯时序 `compute_cross_section` 的旧返回列及最新行语义不变，避免破坏 CLI 兼容；新研究路径明确使用 `compute_matrix`。没有宣称旧 CLI 的各股最后一行是同日截面。
- 输出必须完整匹配时间与标的轴；不静默重排、丢列、增加股票或覆盖重复因子。不存在行情的格即使算子返回常量也保留缺失。
- 合成算子约定：同一时点的有限值平均并列序号／有效数量，至少两个有效标的；滞后不允许负数；滚动均值要求观测时间并集上的完整窗口。真实因子必须按其原公式选择／披露算子约定，不假定所有库一致。
- 每次执行使用副本；保留取消检查，最多 200 万输入格（字段与观测掩码合计），超限失败而非截断。现有 Web 请求限额继续叠加生效。
- 目录显示 `cross_section_panel`，单股入口明确不可用，截面入口可按权限和数据要求校验。定义摘要包含面板口径源码，冻结原档保留计算时定义；不会把当前定义写回旧档。

## 验收范围

`tests/unit/test_factor_panel.py` 使用只在测试注册的合成因子覆盖：

1. 手算排名、并列、常数、单有效样本、缺失／非有限／nullable 数值；标的换序不变。
2. 分钟精确时间、时区等时点、整数日期；缺行的同日对齐与最新日期空值。
3. 错误输入、元数据混用、错位输出、隐式补信号、原始行情不被修改、重复标识与资源上限。
4. 滞后／滚动窗口、缺失中断后恢复，追加未来行情不改变过去值。
5. 真实冻结 SZ000001、SZ300750、SH600036 的 NONE／QFQ／HFQ 三种复权，逐时点以独立标量循环核对排名；不是将合成标的当真实证券。
6. 一次整池计算进入既有 IC／分层／多远期报告；保存完整输入、只读验证不执行、显式重算不取新行情且不覆盖原档。
