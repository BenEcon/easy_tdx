# 因子收藏与多序列原值对比 · 2026-10-10

本批本地实现与验收。继续沿用当前因子注册、计算结果和云存档，不增加另一套因子体系，不修改缠论／MyTT 或统计规则，不部署生产。

## 操作

1. 量化研究 → 因子序列：每项旁的星形按钮收藏／取消收藏。“仅看收藏”仍受当前因子库、关键词和可用性条件约束；收藏不会替换已选因子、修改参数或触发计算。
2. 因子检验使用同一账户收藏；当前不适用于截面检验的因子不会因收藏而绕过限制。保存的是规范因子标识，不是窗口参数或自动选股规则。
3. 运行因子序列后，在“因子曲线布局”选择“多因子分轨对比”。默认选入前四条成功返回的因子，可逐条切换，最多同时四轨；计算仍最多十二个因子，未显示的曲线数据保留在完整明细和导出，未截断计算。
4. 分轨使用共同日期、联动指针与缩放范围，每轨有自己的原值数值轴。不将不同量纲强行叠加、不做归一化或方向反转、不插值或把缺失补零。单因子视图保持原入口。
5. 全屏和手机纵向滚动沿用现有 ChartFrame；数值精度选择影响提示与表格，不影响原始数据。小量级纵轴使用自适应刻度以避免多条轴标均显示为“0.01”。联动提示只显示一次日期，并按分轨顺序显示各因子数值。
6. 保存到个人云存档后，“查看原档 → 存档曲线布局”同样可选分轨对比。只绘制原档已有数据，不查询当前因子目录，不重新取数或计算；旧存档无需迁移。图表布局和当前显示曲线是临时查看状态，不写回原始研究结果。

## 账户与保存语义

- 使用现有带账户标识的偏好 PATCH 和串行队列，独立键 `factor_favorites_v1`；不覆盖复权、股票历史、追踪组等其他键，不另写跨账户 localStorage。
- 同一浏览器共享收藏写入状态，保存期间禁用其他收藏写入，防止相邻入口用旧数组相互覆盖；切换账户／退出立即切换收藏并清除旧错误，旧账户迟到响应不更新新账户状态。
- 成功以服务端回执为准；其他偏好先完成而带出待保存补丁时，也不提前标为已收藏。失败保留已确认收藏并提示重试，不假称成功。
- 收藏数组最多 512 个 ASCII 标识，去重、检查类型和长度；未来暂不在目录中的合法标识保留，异常设置不静默覆盖。规范标识统一别名，研究原始标识不改写。
- 同一账户在多个设备上同时修改收藏，沿用整键最后成功写入的偏好语义，尚非逐项跨设备冲突合并。刷新账户／重新登录读取服务端最新值，不声称实时跨设备推送。
- 收藏与查看操作不是主动行情查询。初始化、切换图表、读取存档和自动取数也不新增主动查询计数。

## 视觉与交互

按前端设计技能采用现有暗色、轻分隔、紧凑筛选和渐进展示；不添加卡片墙。内容顺序为目录／收藏筛选 → 现有计算配置 → 原值图表／分轨切换 → 完整明细。星形按钮提供名称、按下状态、焦点轮廓；过渡遵循减少动态效果偏好。

实际 WebKit 验收发现通用全屏容器会把多个子元素横排，导致手机绘图区仅 154px；改用单列工作容器后绘图区 340px，390px 文档无横向溢出。四轨纵向滚动，不压缩成不可读小图。其次修正重复日期提示和小量级重复轴刻度。
