# 多周期研究来源与失败记录（2026-10-10）

## 本轮完成范围

五周期／多周期研究现在保存实际完成时的冻结结果，而不是在点击保存时重新拼接当前表单。原雷达来源独立保存，不能代替研究行情，更不能把原扫描中的未来后缀注入历史回放。来源仍标注为账户上传、非服务端认证凭据；旧存档不补造来源或新规则版本。

- 保存全部选定周期及每个周期的取数／计算失败原因。部分失败不再从结果中消失；全部取数失败可保存明确失败报告，不调用研究计算、不生成结论。
- 新增可选 `study-collection-v1`：选定周期、completed／failed／not_started 执行状态。前后端共同校验周期唯一性、结果覆盖、输入范围和失败状态；旧存档保持兼容。
- `completed` 仅指取得计算响应，不表示每个周期成功。空行情仅允许明确的全取数失败记录；这类记录不能显式重算，必须重新主动查询。
- 输入、账户或组件生命周期变化使旧请求失去写入权；结果保存核对实际 owner 与冻结上下文。异常响应、重复／额外周期、错误截止日不冒充成功。
- 导出、导入、云端原档及显式重算另存保留独立来源；普通查看不取新行情、不重算。原扫描任务删除后仍可阅读保存的来源。
- 自动研究及自动补充周期保持 `X-Query-Origin: system`；手动更新包括失败取数标记为 `user`，避免系统查询进入用户主动查询统计。

界面遵循 frontend-skill 的紧凑深色应用风格：复用折叠来源说明，增加短状态摘要，不增加装饰性卡片。Playwright 用于真实浏览器验收。
