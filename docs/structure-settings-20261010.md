# 缠论结构计算设置 · 2026-10-10

## 入口与语义

缠论结构左侧、均线系统上方新增默认收起的「结构计算设置」，复用 MacSelect、NumberStepper 及现有侧栏样式。

- 默认新笔，可切换老笔、简单笔；只选用已有间距规则，不修改 `bi.py` 的严格价格条件、分型规则。
- 基础中枢最少线段数默认 3，可选 3–6，与现有策略参数范围一致。
- 这是基础层输出筛选门槛，而非将标准三段核心重新定义为 N 段核心。筛选基础中枢及结构信号；信号按其确认当时的 `centre_segment_count` 判断，不用中枢后续延伸补足旧信号。保留原中枢形成/退出时间及原始索引，不伪造新的形成日。
- 不筛除独立 MACD 提示，不修改高层递归门槛。成笔规则变化可能改变输入线段，从而影响递归结果，这不等于改变递归算法。
- 设置按当前页面使用；刷新返回默认值，新存档保留实际设置。未加入跨账户共享或隐式全局默认。

## 一致性

主图、行业对比、跨周期图、审核回放、多周期概览、归属历史、穷举/失败追踪请求统一携带设置。
更改设置立即取消旧请求并清除旧主图和对比，需重新分析。研究游标指纹包含设置，禁止跨参数续接。
多周期方向观察及逐根历史使用相同成笔配置，不再固定新笔。

图表结果、多周期研究参数及存档保存实际设置。显式重算使用原档设置；没有此字段的旧档按已有新笔/3 段默认，并提示不是原版本复现。原档不被覆盖。前端拒绝参数不匹配的重算响应。
