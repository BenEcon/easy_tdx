- 股票池：007、008、012、016、017、036、041、045、090、108、114、120、124、131、163、170、179。
- GTJA 累计 153 个真实公式：114 时序、39 股票池。未实现的 38 个不注册为可选假功能。
- 所有新增项具备中文名称、独立标识、明确输入、命名窗口、依赖预热、公式和来源版本、复权限制。013/120 无可编辑窗口，不接受虚构参数。
- `R` 使用明确股票池同日平均并列序号/有效数量，至少两只；`TSRANK` 使用单股完整时序窗口；不互相替代。

默认预热依次为：007=4、008=5、012=10、013=1、016=9、017=15、026=235、036=7、041=8、045=164、090=5、108=125、114=7、120=1、124=31、131=84、154=197、163=20、170=20、179=61 根。131 的三层窗口是 50+17+17=84，不是 85。改参后动态重新计算依赖路径，超过 600 根不静默缩短。

## 来源、差异与不伪造原则

继续使用固定审计源：2017-06-15 国泰君安数量专题报告 93，第 11—16、31 页；DolphinDB Apache-2.0 模块固定提交 `43ace2cc4b81d048864ec2e40c25728d5d464e05`。本批逐页视觉核验原公式并独立写 Python，不复制 BenEcon 受限代码；沿用项目 NOTICE 和 Apache 许可记录。

- 原报告 SHA256：`863f62c2e23bd87ddb42b8338c8fe2b0276d94260ac985e1a0edfff318693c6c`。
- [原报告](https://guorn.com/static/upload/file/3/134065454575605.pdf)、[固定参考模块](https://github.com/dolphindb/DolphinDBModules/blob/43ace2cc4b81d048864ec2e40c25728d5d464e05/gtja191Alpha/src/gtja191Alpha.dos)。不重新分发研报或改变版权。
- 007 遵循因子表的外层括号：两个排名先相加再乘量变排名。参考模块实际代码漏括号，不能直接沿用其优先级。
- 原报告算子表将 MIN/MAX 定义为两值比较，但部分因子表又采用 `MIN/MAX(序列,整数)` 写法。007、017、041、108、154 明确采用滚动窗口解释，并在页面限制中公开该歧义；不声称已证明原文唯一解释。108/154 不照搬参考模块中未明确滚动的 `min` 调用。
- 131 把 `DELAT` 解释为 DELTA，滞后一根；不凭拼写错误虚构新算子。
- DECAYLINEAR 对旧到新样本赋 1…w 权重再归一化。不是此前 027 的指数 WMA。
- 114 保留嵌套除法。W=C 时内层分母为零，不能代数约分后假造 0；H=L 时同样未定义。
- 154 按因子表比较价格差与相关系数，不自动标准化。任一侧缺失返回空值，不将布尔比较结果伪装为 0。
- 017/108/131 先核实底数和指数有限，避免 `NaN**0` 或 `1**NaN` 被误输出为 1。溢出不参与排名。
- 036 逐窗口稳定求和，防止历史浮点累计残差把两个真实 0 拆成不同截面排名；不引入任意 epsilon 合并不等值。

W 仅为已核验的实际成交额（元）/实际成交股数。研究入口延用原量额契约、原请求与日期对齐验证；复权输入明确拒绝，不自动改用户选择，不按收盘比例猜复权 VWAP。零量时均价为空；不使用收盘价、典型价或补零替代。内核也拒绝显式 QFQ/HFQ VWAP；无元数据的数学测试输入不代表生产数据合格。

## 真实冻结数据与测试证据

除原 12 组 160 根多股票、多周期、多复权样本外，新保存 11 组 320 根 MAC 不复权公开样本：十只股票日线，以及 300750 的 30 分钟线。目录 `tests/fixtures/factor_vwap_long/`，每份保存来源节点、标的、周期、实际/请求复权、观测时间、请求数量、原始 bars 摘要；另有 SHA256SUMS。它们是当前供应商快照，不是历史版本/PIT 证明，也不是投资推荐。

`scripts/freeze_factor_units.py` 增加显式 count/adjust/stock 参数；最多 800 根、20 个不重复公开样本，不覆盖现有文件、不访问用户配置。默认原采样行为保留。没有为了通过测试把真实股票价格重新缩放。

原三只股票在长样本中的价格排名恒定，016/036/090/179 的排名相关应为空。保留此反例，并补充价格排名实际交叉的十股池；20 个新公式的默认窗口均得到真实有限输出，逐行与独立计算对照。对于 026/154，320 根也真正跨过默认预热，不拿 160 根全空结果算验证成功。

## 浏览器验收与使用

本地 WebKit 隔离账户与数据库，页面沿用现有暗色紧凑布局，没有平铺新卡片或新建第二套因子平台。浏览器使用合成验收行情，不是所显示股票的实盘报价。

已验证前复权下 013 禁用且明确提示缺少复权成交价变换依据。手动选择“不复权”，在 GTJA 库搜索 013/026，选择后将 026 相关窗口改成 7 并执行任务，返回完整 160 条合成验收记录。导出的实际 JSON 保存 NONE、013 无参数、026 完整实际参数 `{mean:7,lag:5,corr:7}`、v7 版本、预热 12、真实量额单位核验方式，显式复算不取实时数据且值不变。请求 500、实际返回 160 均保留，没有伪称取得 500 根。

实际点击保存到测试账户成功；导航账户页刷新后仍有新原档，重新打开的摘要 `b820e6873053` 和版本保持一致。两次只读打开监测均没有因子计算/检验 POST 或 `/api/v1/bars` 请求；后端冻结复算另有禁止实时 fetch 的断言，不能仅用浏览器短观察证明所有后台行为。

桌面 1440×820 和手机 390×844 截图已实际检查，保持原暗色样式；手机文档宽 390、原档弹窗宽 374，无全页横向溢出。截图在工作区上级 `output/playwright/gtja-vwap-desktop.png`、`gtja-vwap-mobile.png`；导出的完整原档 `gtja-vwap-series.json`，只读监测 `gtja-vwap-readonly.txt`、`gtja-vwap-refresh-readonly.txt`。本批没有另跑新增股票池因子的浏览器交互，17 项的端点、冻结原档与独立计算已逐项验证；不将此前批次的截面截图冒充本批新证据，完整系统端到端验收继续保留。
