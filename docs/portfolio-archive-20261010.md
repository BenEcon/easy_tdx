# 组合／多策略完整原档（本地，2026-10-10）

## 范围与操作

组合回测及策略库多策略结果区新增“读取完整原档”。显式读取已完成任务后，可导出 JSON 或保存到账户云端；账户页支持导入、查看、回收站及恢复。原策略库保存／载入功能保留。

- `portfolio-evidence-v1`：原任务编号、原执行版本、读取时版本、存储方式、完整规范化请求、按原顺序排列的全部成员行情与元信息，以及完整原结果。
- `portfolio-research-v1`：封存上述回执及标题／保存时间。原字段、精度、空值指标、绩效口径、净值、成交、持仓、资金分配和未知扩展字段均保留，不按当前表单重建。
- 查看采用现有深色紧凑界面，汇总与成员分层；成员下拉可切换原行情、成交和净值，版本／配置／持仓按需展开。未保存指标不补算，不重新评级；不进入缠论重算流程。
- 已保存副本不依赖原任务继续存在。原任务已清理、旧任务未留输入、账户不匹配或校验失败时明确报错，不改取最新行情。

执行版本只是标识，不意味着原档包含可运行的旧算法。导入是账户提供的数据，不作为服务端认证凭据或数据真实性证明。

## 后端与隔离

内存模式的组合和多策略提交统一编码冻结输入，再从该输入分派计算；读取也使用同一份冻结输入。持久模式继续读取已有无损任务输入，支持任务库重新打开后的读取。读取不发起行情查询或回测。

逐成员核对请求顺序、标的、周期、复权、原标签、原指纹、最后收盘时间及成员结果／分配键；不使用当前策略注册表改写旧标签。无成员遗漏或额外成员才能封存。相同股票不同周期、不同标签的策略可独立保存。

检查发现引擎结果字典会覆盖重复标的或重复“策略标签＋标的”键。本轮在计算前拒绝这类歧义输入，明确要求区分策略槽位名称；不静默去重或改变资金分仓。没有调整信号、撮合、成本和绩效公式。

读取受数据请求资源额度限制，响应 `no-store`，完整回执超过 25MiB 明确拒绝，不截断。新增云存档类型沿用既有上传额度、本人会话隔离、版本冲突、删除恢复与成对备份。前端读取及捕获校验 owner、任务、请求和结果；账户／输入／离页／运行状态变化丢弃迟到响应。读取原档标记 `system`，不计入用户研究查询。

## 首轮发现与修正

初轮校验将引擎的成员数 `2.0` 错当无效整型，改为有限数值且精确等于成员数，仍拒绝布尔值。TypeScript 回调中的收窄通过局部常量保留，未绕过校验。测试导入排序经 Ruff 修正。

浏览器验收脚本曾使用错误登录按钮名、将 combobox 当 button、误调用内存任务不支持的持久删除接口；本机 QA 清理路由又被 SPA fallback 遮挡。已修正测试脚本与隔离 QA 路由顺序后重新完成验证，未改生产删除语义。多策略确认对话框使 CLI 未输出完整返回值，另行独立读取两个副本、核对原任务 404，并重新执行只读和三尺寸验收，记录在 `browser-multi-verified.log`。
