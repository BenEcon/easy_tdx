# 背离信号口径

本版将 MACD 指标提示与笔中枢级趋势背驰分开，不把指标背离直接标为一买。

- 双线背离：同一零轴侧的价格新极值相对前一有效极值，DIF、DEA 同时向零轴改善；不限制柱色。下一个较高低点/较低高点确认指标局部极值，这不是严格缠论分型确认。
- 波段背离：按柱正负划分 A/B/C；A、C 同向，B 反向。C 价格破 A 极值、同向柱绝对面积更小、段内 DIF 和 DEA 极值改善且仍在趋势侧。零柱沿用前段，第一段不完整波段不作 A。C 柱收缩时可产生候选，变为反向柱后核验完整面积并确认。
- 趋势背驰：额外要求本系统识别的两个同向不重叠笔中枢、进入和离开段以及力度条件成立；仅该事件产生一类买卖点。该结构检测仍依赖既有笔/中枢算法，不等于对所有级别缠论结构的完整实现。
- 顶部条件对称。未改写既有二、三类买卖点规则。

事件分别记录极值日期、首次提示日期、确认日期和对照日期。确认不代表后续价格必然反转。未确认候选因新极值或力度条件失效而被替代时，留在事件列表中但不继续绘为有效图表标记。一类回测信号用实际确认索引，不用极值日期。
