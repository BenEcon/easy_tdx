# 背离信号口径

本地升级版将 MACD 指标提示与确认线段基础中枢的结构背驰分开，不把指标背离直接标为一买。尚未发布；尚非高层级递归模型。

- 双线背离：同一零轴侧的价格新极值相对前一有效极值，DIF、DEA 同时向零轴改善；不限制柱色。下一个较高低点/较低高点确认指标局部极值，这不是严格缠论分型确认。
- 波段背离：按柱正负划分 A/B/C；A、C 同向，B 反向。C 价格破 A 极值、同向柱绝对面积更小、段内 DIF 和 DEA 极值改善且仍在趋势侧。零柱沿用前段，第一段不完整波段不作 A。C 柱收缩时可产生候选，变为反向柱后核验完整面积并确认。
- 趋势背驰：要求确认线段基础中枢、前后两个中枢外围同向分离，以及进入和离开段 A/C 的 MACD 力度过滤成立；该事件产生基础一类买卖点。不等于所有级别缠论结构的完整实现。
- 盘整力度背驰：A/C 过滤成立但不满足前后中枢外围分离，只输出盘整力度提示，不输出一类买卖点。仍是带 MACD 过滤的研究口径。
- 二类追溯一类后的首次反向段与回试；弱二类保留结构标识，但策略默认过滤，可单独开启。三类要求第一次完成且不进入中枢的回试，允许二三类重合。
- 顶部条件对称。图表、雷达策略、回测及买卖点因子采用 confirmed_segment_base_v1 来源；旧笔重叠中枢仅保留为辅助 API 数据。

事件分别记录极值日期、首次提示日期、确认日期和对照日期。确认不代表后续价格必然反转。未确认候选因新极值或力度条件失效而被替代时，留在事件列表中但不继续绘为有效图表标记。一类回测信号用实际确认索引，不用极值日期。
