# 云原档完整图表指标重算

2026-10-10：本地实现与定向验收完成，未部署。原十阶段计划仍有其他未完成项。

## 功能与边界

- 旧档只读预览不重新计算。明确检查并确认重算后，有冻结指标的周期同时计算结构、MACD、所有已保存的主图均线与全部指标实例，包含未勾选的已保存均线；原有显示顺序、配色、线型、参考线与开关状态保留。
- 参数来自原档，不来自当前页面选项。当前技术指标目录的 36 种选项均支持（包括无指标、成交量）；相同指标可以有不同参数实例。成交量包括 MAVOL5/MAVOL10，MACD 使用原参数调用现有未四舍五入的计算器。
- 仍只计算完整保存窗口，不获取更多行情、不重新复权、不截短。结构计算继续当前结构算法默认值；指标重算不代表旧结构版本复现，也不宣称行情已被独立核实。
- 缺少冻结指标的旧周期明确列为“仅结构与 MACD”，不从当前设置推测旧参数。有冻结记录但参数缺失、未知指标/输出列、非法参数或计算失败则拒绝该次完整重算，不沿用原数值冒充新结果。单周期上限 800 根、最多 30 条均线和 8 个指标实例；均线/整数参数周期 1—8000，原样保留超过行情长度而未预热的 null。
- 请求中指标参数纳入输入摘要；计算前后核验执行源码/运行时版本，不发布混合版本。完整图表响应使用 `archive-recompute-v2`，未请求指标的兼容路径保留 v1。新副本保存原档 ID/摘要/revision、实际参数、执行版本及前端数值投影版本。均线和指标值由服务器计算，前端仅按已保存布局投影，不另行取数或套用默认值。
- 对照覆盖结构和冻结指标逐字段差异，保留全部精度、缺失/null/0 区别；不等同于按信号身份配对的语义对照。新副本使用独立 ID，原档不改变；重新打开新副本直接使用保存的指标，不再次查询。

## 一并修复的缺失值问题

原 `buildIndicatorSeries` 使用 `Number(null)`，将指标预热期空值变成了 0。现在普通指标只接受有限数值，其余显示为缺失；不修改已冻结旧值，所以对照可见旧 0 与新 null 的差异。FK 是计算器明确返回布尔值的例外，按定义转换为 0/1；没有把其他指标的 false/string 误认为数值。底层 MyTT、缠论、M1 及高层递归算法未改。
