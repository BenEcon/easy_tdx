# 背离与买卖点事件版式深化 · 2026-10-05

已随 `easy-tdx:period-compare-20261005` 部署，浏览器回归及公网资源验证通过。发布与恢复信息见 `period-compare-20261005.md`。

## 设计与范围

- 新增共用 `ResearchEventRecord`：桌面日期侧栏、标题与状态、元信息、原始说明、按需展开依据；560px 以下容器转单列。
- 买卖点分为结构性买卖点与 MACD M1 提示两个独立可折叠区块，默认展开。MACD 提示来源与筛选保持不变，不计入结构性买卖点。
- 原始记录缺少确认时间时明确显示“确认时间未提供”，不伪造确认日；分钟时间完整保留，不转换时区。
- 背离日期摘要分别展示对照及首次提示、确认或失效日期，保留所有原始事件和判定依据。
- 回放增加可选 caption，仅调整可见行标题；原 label、按钮可访问名称、索引校验及 seek 事件保持不变。
- 核验规则用四类说明表，时段旁显示通过项数。明确该计数不代表信号强弱或胜率。
- 延续统一缩进、简洁分隔与低饱和配色，无新增过滤、不改变信号计算。
