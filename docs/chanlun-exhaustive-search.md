# 固定工程规则下的完整分解搜索

## 已确认的边界

2026-09-29 用户确认按现有工程规则穷举。对有限固定行情，固定已配置的笔、基础线段、中枢生命周期和完成门槛，搜索各层全部互不重叠的局部候选子集。严格成笔价格、原图 MACD、相邻反向确认、来源归属及整区父走势释放规则不变。

包括非最大子集与空子集：不选择候选时，来源保持未完成／未解决，不强迫拼接。这不是原著所有笔划分、中枢解释、结合律形式的数学穷举，也不把未完成来源冒充自然完成走势。默认分析和交易出口不变。

## 覆盖性理由

1. 每层实际检测器扫描合法连续输入链的所有起止窗口，得到带类型、确认时刻及相邻反向依据的候选。
2. 按稳定顺序逐候选做选／不选二分。与已选来源重叠的候选只能不选，这是互斥规则排除，不是启发式剪枝。无宽度限制、随机抽样或固定层数上限。
3. 每个低层选择均重新生成高层输入、中枢、候选、反向依据和归属。不借用其他分支的父走势或释放状态。规则要求相邻反向结构，其不同合法解释通过低层选择产生，不允许跳过近端见证任意选择远端见证。
4. 每个上层走势消费多个同级输入，层级严格收缩。有限基础输入、有限候选、有限二分支及有限深度构成有限搜索树。
5. DFS 二进制路径记录叶子；从最后一个选中位回退为不选，其后重新展开。仅无可回退位时返回 `complete=true`、`next_cursor=null`。空候选输入仍有一个全部保留未完成来源的解释。

测试另以独立 powerset 比较单层完整集合，并验证高层随低层选择改变，不只核对结果数量。

## 接口和资源边界

- `POST /api/v1/chanlun/replay/exhaustive`：沿用回放行情模型，先按 `visible_count` 截断再分析。每批默认 2 个、最多 8 个叶子；2 秒软预算在完整叶子之间检查，超时不等于完成。单个复杂叶子仍可能较慢。
- `cursor` 保存下一路径和累计数，HMAC 签名并绑定规则版本、股票、周期、可见行情。篡改、用途错误或快照不匹配返回 422，不接纳客户端完成声明。`solution_token` 精确重现指定分解。签名不是加密，令牌不包含账户凭据或行情正文。
- 网页入口：缠论结构 → 归属时间轴与分解研究 → 完整分解搜索与失败追踪。默认折叠，支持连续搜索、停止、续接、首批／前后批次、指定分解追踪。
- 只保留当前批完整快照及轻量检查点，不积累全部结构图；检查点列表仍随批次数增长。最坏耗时指数增长，不承诺任意输入瞬间完成。停止取消浏览器请求及后续批次，服务端正在运行的单批可能继续结束，不另起后台搜索。关闭页面不自动恢复。
- 未设置 `EASY_TDX_RESEARCH_CURSOR_KEY` 时启动生成临时密钥，重启使检查点失效。多 worker 或跨重启续接需统一配置独立随机密钥并安全保存；本轮未修改服务器配置。

## 完整失败追踪口径

`POST /api/v1/chanlun/replay/candidate-audit` 对默认或指定分解重跑实际路径，不用猜测性影子检测器。网页每页 50 条；接口允许 1–100 条。

- 输入入口记录首条无法进入连续已确认基础链的原因及未接纳后缀数量。后缀不再具备候选前置条件，不称每项都已独立检查。
- 合法链中趋势／盘整分别覆盖全部起止窗口，包括单结构、早停和剪枝后缀。分别记录结构不足、端点失败、中枢升级／不分离、进入段缺失、MACD／价格失败、反向等待及同批失效。
- 递归断点记录未完成来源缺口或接点／时间不连续；所有跨断点窗口因前置条件失败而不评估，不补造候选。
- MACD 十项：区间有序完整，DIF/DEA/柱体覆盖，价格严格新极值，同色柱面积缩小，双线零轴／极值及中枢回拉。数据完整时记录全部可独立评估项；前置不足显示未评估，不表示通过或失败。显示舍入不参与判定。
- 候选形成后另记本分支选择／未选择、实际归属检查和最终准入位置；未选择不是规则失败。最终父子、外部准入沿用递归核验器。

完整指每个入口都有实际失败、待确认、形成候选或前置规则排除的去向，不在失败前置条件后编造反事实结果。

- 独立运行修改前恢复副本与新默认引擎：12 组顶底镜像 M2/M3/M4 及历史截断完整快照逐字段相同。
