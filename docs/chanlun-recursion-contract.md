# 保留延伸、扩展的递归：实现边界

2026-09-24 用户确认采用保留延伸、扩展的模式，而不是固定三段盘整分组。

## 已实现的可证明子路径

来源：用户提供课程前半部分第 33 课九段延伸及结合律说明；后半部分第 99 课要求优先保证升级中枢的成立。

`extension_hierarchy` 是**延伸重组证明**，不是完整自然走势分解器。

- 基础输入仅为连续、已确认的线段。它们在此定义最小输入层，不代表日线/周线级别。
- 先沿用基础中枢生命周期，只有已纳入的组成线段参与计数。等待首次回试的离开段不参与；失败回试后才纳入，并记录实际可知时间。
- 同一个中枢内至少九条连续组成线段，才尝试三级分组证明。每组三条的价格区间必须有正宽度交集；再验证三个完整子区间的交集。不是“数量达到九就算成立”。
- 更高层递归重复该证明，当前保守路径需要 27、81……条同一基础延伸内的线段。只验证这条充分条件路径，**不把它宣称为所有高级别中枢的必要条件**。
- 每个节点记录全部来源线段、三个子区间、固定交集、外围、端点和可知时间。重复出现的来源证明保留相同时间，不因更高父节点形成而推迟。
- 按输入前缀计算最早可知时间；不能将最终成员列表用于回填历史。根节点形成证明固定，后续加入不重写。
- 重组产生的子区间不是自然走势终结信号，`natural_type_complete=false`；不送入交易策略生成新信号。

## 仍然未实现，不得标记完成

1. 自然走势类型在延伸、趋势延续、反向形成之间的起止与完成证据。
2. 两个不同基础中枢外围重叠后的完整重组：外围交集不是新中枢核心，两个基础中枢退出也不能直接当作三个已完成次级别类型。
3. 跨独立中枢、连接段和混合低级别结构的递归组合，以及更高级别中枢自身的离开/回试生命周期。
4. 上述完整结构到策略、雷达和回测的逐时点传播。

因此 `structure_metadata.recursive_levels_ready` 仍为 false，仅新增 `extension_regrouping_ready=true`。
界面明确展示该边界。完成第 1–3 项并验收前，不得把这一子路径描述为“高层级缠论递归已全部完成”。

## 跨中枢重组候选搜索（第十七批）

新增 API `expansion_regrouping`，独立于已证明的延伸树，不自动绘为高级别中枢。

- 准入仅限相邻基础中枢核心分离且外围相交/触及。两个中枢均退出前只记录等待状态，不生成切分。
- 搜索从前中枢初始线段到后中枢退出回试段的连续来源区间，包含连接段；这是结合律下的替代重组，不改写原归属分解。
- 每个分区至少三条确认线段、恰有一个未达到九段延伸的基础中枢。各分区起末线段方向与净方向一致，三分区方向交替；三个完整分区的价格范围须有正宽度交集。
- 按第一切点、第二切点从早到晚选首个有效候选，不声称这是原文唯一自然划分。不能验证的情形保留无候选状态，不用外围交集充当核心。
- 已九段升级的输入保留为需要高层级输入，避免把它重新当成普通基础类型。
- 输出 `candidate_core`（候选核心）与 `envelope_overlap`（旧外围交集）两个独立字段。成熟候选记录实际可知时间；各分区记录来源、种子、方向、极值、价格范围及可知时间。
- 分区仍为自然完成**待验证**状态；`higher_level_confirmed=false`、`natural_type_complete=false`。这一搜索不能代替自然走势完成判定，不能输入高层级策略。

## 候选分区完成依据审计（第十八批）

`expansion_regrouping.completion_audits` 与固定的候选形成记录独立：

- 用保守的“方向极值包围”条件检查起止点。向上分区的起点/终点分别对照全区间最低/最高，向下反之；这是当前实现的保守准入条件，不声称是原文全部重组方式的必要条件。
- 单独记录起点、终点冲突及预期极值。原候选核心仍仅是几何重叠结果，审计不把它改名为已确认中枢。
- 查看分区之后的首条已确认反向基础线段，并记录实际可知序号及日期。未确认、越界或断链后的线段不参与。此证据只证明次级别转折，不证明同级别走势完成。
- `as_of_index/date` 是本次审计截止；`known_index/date` 仍是原候选形成时刻，不能混用。随着新线段确认，审计可更新，但成熟候选不会被覆盖。
- 所有分区仍包含 `same_level_completion_unproven`，`eligible_for_recursive_input=false`。没有通过把布尔值改成 true 来伪造自然完成。

当前样例的第二分区起点 115 低于内部最高 116，第三分区终点 110 低于内部最高 113，均不满足该保守准入。后中枢回试结束只是第十七批几何搜索的固定窗口终点，不能默认当作自然走势终点。后续需要结合后续结构重新研究自然边界，而不是固定该切分后强制确认。

## 验收要求

- 上下镜像、8/9、26/27、80/81 临界点；第九条为待回试离开段与失败/成功回试。
- 每个父节点来源与子节点扁平化严格相等，子区间不重复、不缺失，核心按完整子区间求交。
- 确认时间不早于所有依据；任一历史前缀与最终证明按可知时间筛选一致。
- 输入断链立即停止，不能跨断点凑段数；非零编号、空输入、数据截止及合并 K 线真实极值位置保持正确。
- 合成图仅作构造样例，不冒充真实证券的高层级验收。
