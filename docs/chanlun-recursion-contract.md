# 保留延伸、扩展的递归：实现边界

## 固定工程语法穷举与实际失败追踪（第六十二批）

用户确认按现有工程规则穷举。新增独立搜索遍历每层所有互斥候选子集、重新计算上层及归属，保留未完成来源；只有 DFS 回溯耗尽才完成。默认选择器和交易输出不变。每个合法链起止窗口、剪枝后缀、输入／递归断点及独立 MACD 门槛都有实际判定去向，不把未执行的后续条件写成失败。详情见 [穷举范围与验收](chanlun-exhaustive-search.md)。这不等同于原著所有可能解释的理论穷举。

## 实盘验收、下钻和独立研究入口（第六十一批）

- 冻结均胜电子 800 根原生 MAC 前复权日线，保持原始 OHLC 精度。7 月低点、双线/波段底背离、候选替代及确认日分别验收；详见 `chanlun-real-market-acceptance.md`。当前 QFQ 快照不等于历史数据版本，MACD 背离不自动成为一买。该实盘样本没有合格 M1 父走势，不能用作 M2/M3 实盘正例。
- 父子下钻使用经依赖图验证的实际 child/opposite ID，逐层查看，反向确认不加入价格覆盖。图表定位只读取当前快照，保留原始索引；三种定位分别为本走势、MACD A/C 比较段、反向确认。不重算或改写既有结构。
- `POST /chanlun/replay/release-history` 每批最多 40 个连续原始前缀，批次边界也独立重算。先截断原始行情，再重建基础结构和全域递归，保存前后状态差；不以最终已确认线段反推过去。网页按需批量重建，可停止、续接；查询/快照更新取消旧请求并清理结果。停止客户端请求不保证正在执行的当前服务器批次立即中断。
- 归属缺口说明限定于已局部完成的结构：实际归属区、所需层级、未覆盖来源以及子/反向依赖路径。尚未形成候选的原始来源仍没有完整逐关卡失败日志，不猜测其唯一 MACD 或中枢失败原因；这部分仍待后续完善。
- `POST /chanlun/replay/release-comparison` 提供 earliest（现有默认）、widest、latest 三种确定性选择顺序，各层重新运行原来的结构/MACD/反向确认/归属校验。非默认选择只能经独立研究入口使用，不传给主分析或交易策略；网页切换不改变主图。较晚可用优先是当前可见截面的研究选择，并不预知未来。
- 研究结果明确 `exhaustive=false`。它不是所有合法结合律分解的穷举，也不是原著等价证明；三种结果可能一致。研究面板回放跳转到相应日期的默认分析，不能把选择顺序差异冒充历史信号变化。严格成笔、默认选择顺序及交易信号不变。

## 联合快照的依赖图交叉校验（第六十批）

“全域走势递归”的网页审核必须验证来源与声明互相一致，不能只因为来源编号连续就接纳快照。本批不修改后端识别算法和已确认完成规则。

- 核验逐条结构的规则、类别、方向与起止价格，要求原始索引为合法整数。高层父级起止必须与真实次级链吻合，各接点的价格、时间、交替方向和相邻反向见证一致。
- 归属域的实际输入 ID、层级、成员接纳来源与时间必须对应。来源列表完整拼接，不允许缺项、未知归属种类、未来时间或高层归属指向错误输入。
- 根据当前真实来源范围交叉核对整区覆盖、区内约束、部分覆盖、外部见证冲突，并传递全部子级和反向见证的未解决归属。当前核验时刻不能早于依赖的当前核验时刻；不替换原完成时间。
- 从合法记录核验最终互斥代表集合。父级替代、子级 `represented_by_id`、未解决清单、域释放者和来源覆盖必须相互一致；被拒绝父级不能冒充当前代表，不能静默漏掉未解决记录。来源覆盖的原始端点也须与实际代表及相邻覆盖块吻合。
- 校验失败沿用现有“来源或确认依赖无法核验，请重新分析”提示，不提供这份异常快照的递归审核/回放入口。不影响其他分析模块，不修改输入快照。

这是对后端已提供依赖图的一致性验证，不是前端重新计算 MACD、中枢或基础线段，也不证明一个全量伪造但自洽的数据集是真实行情。原合法输出、严格成笔、交易准入和理论等价声明不变。组件布局未改。

## 整区父走势释放与跨域递归（第五十九批，已确认工程口径）

本节是当前规则，后续各批为历史记录。用户明确采用：更高层父走势完整覆盖相关归属区，且独立通过同级中枢、原图 MACD 背驰及反向次级结构确认后，仅由父走势对外递归，内部子走势不重复使用。这替代新解释中的永久隔离；不修改旧 T/M、第一版及第二版归属解释，也不宣称与原著所有自然分解唯一等价。

桌面原始文档已重新找到并复核，包括 `0928.docx`、前后两部分缠论文档。继续保留 0928 中严格成笔价格与前三笔重叠等既定选择。原文关于中阴状态、结合律及更高层中枢优先的讨论用于边界审查，不把工程释放判据冒充原文直接给出的算法。

- 新入口 `released_movement_snapshot` 按实际已完成的趋势/盘整逐层收缩，没有写死最高层数。只拼接同级、连续、方向交替、端点与确认时间合法的真实来源；缺口和混级连接不补造完成单元。未满足条件的末尾和中间来源保留待解决，非强制全部完成。
- 延伸、扩展形成的归属区本身不是走势完成。实际升级证明决定最低父级要求，不能凭任意来源数量直接提升。父走势必须完整覆盖整个归属范围，局部覆盖或层级不足不能释放。
- 局部完成但暂不能外用的子结构作为隔离依据保留，允许独立父级检验；它们及其后代的未解决确认归属都沿依赖链传递。父级仅在完整覆盖对应域且级别足够时解除该依赖。后来发现的更高层归属还会重新自底向上传递，不能只检查父级直接见证而漏掉远端孙级见证。
- 局部完成时间、用于构建的结构时间、当前归属核验时间分开。后来冲突的可知时间只用于当前核验，不能倒灌为旧子走势的完成时间并破坏其先后链。历史必须按可见原始 K 线前缀重算；不把最新归属倒填旧快照。
- 有效输出前沿按基础来源互斥：合格父级替代其全部已覆盖后代；被拒绝的父级不能遮挡合法下级。反向见证只作确认，不计入本走势价格来源。`source_cover` 将每条可接纳基础线段恰好归入外部完成、区内保留或待解决之一。
- API 增加 `released_movement_recursion`。它是当前时点的完整联合快照，full/summary 选项仅控制旧归属历程字段，不意味着新字段保存了全部历史版本；现有确认前/时刻回放通过前缀重算获取新字段。
- 网页增加默认折叠的“全域走势递归”，可审查来源覆盖、独立完成依据、整区释放、保留约束、待解决父级和两个确认时点。旧归属解释保留但明确标为旧路径，不混用其来源。缺失、损坏或越界快照不生成回放入口。

实现范围是用户确认的、确定性选择的工程递归闭环，不是枚举全部结合律分解。`natural_type_recursion_ready` 与 `theory_equivalence_claim` 继续为 false，避免旧消费者误解为原著理论完备认证；递归结果没有接入交易信号、雷达或自动交易。M 层级也不是日/周/月时间周期。构造测试覆盖 M2、M3、M4 合法跨域释放及保留反例，不代表真实证券识别准确率验证。

## 内部版本树的转交与隔离（第五十八批）

归属版本构建时，内部候选在入口已深拷贝，后续扫描及缓存命中也返回独立证据；记录、来源列表与归属结构均在本次构建中产生。因此内部 `_hierarchy` 将独立结果树直接交给版本构建器，不再对每个完整版本重复深拷贝。

- 仅在提供 `internal_seed` 的内部路径启用；独立旧 T/M 解释保留原返回复制边界。最终 `layered_movement_ownership` 仍深拷贝公共输出，不能将本次优化推广为共享可变输出。
- 不删除入口候选复制、缓存取出复制、历史版本保存或最终导出复制。不同内部版本、调用方候选和缓存之间不得共享可变容器；最终输出也不得引用构建中的树。
- 不截断、跳过或抽样归属版本；full/summary 的地址、日期、历史时点、拒绝明细和递归判定不变。通过对象身份检查、恢复原复制边界的逐字段对照及实际日期接口验证此约束。

这是计算性能优化，不增加自然完成规则、递归层数或交易准入。实际提速受输入和运行环境影响，不代表服务器响应时延保证；整体归属域自然结束、跨域重新组合及完整外部自然分解仍未完成。

## 归属冲突的来源与反向依据明细（第五十七批）

在已拒绝候选中增加可选 `ownership_conflict`，记录本版实际输入层级、候选基础来源、来源涉及的完整归属范围，以及反向确认结构的 ID、基础来源、可知时间和归属范围。未进入内层归属时明确为 null，不猜测归属 ID。

- 基础入口与高层入口共用独立的解释函数；反向确认来源不加入候选价格覆盖。基础版本先按原签名决定是否生成，再为输出复制补充明细，不能反过来改变版本签名或选择规则。高层候选仍按原跨区/见证归属门槛拒绝。
- 明细绑定原版本。如果外部归属区后来扩大而本域解释未变化，本域仍保留旧版本时间及其当时的范围，不用后来状态覆盖旧依据；查看新时点应通过原始行情前缀重算，不能把本版范围误作所有区域在最新时点的联合快照。
- 网页默认折叠展示冲突依据。高层反向 ID、来源、层级及时间必须对应实际记录，涉及归属范围必须与本版内层归属相符；跨界/外部见证的几何关系也须对应拒绝原因。基础入口验证来源归属、单段见证和范围关系；基础见证的原始价格与确认机制不在前端重新计算。
- 明细缺失或损坏只降级该明细，不伪造具体冲突范围；原候选核验通过的来源及回放仍可用。当前字段只提供归属范围，不提供跨版本稳定的归属标识，也不据此声称自然完成。单项清单取消内部限高，多个候选仍可滚动。

严格成笔、MACD、旧 T/M、第一版归属、全部原字段与版本时间不变。不新增交易信号，不解决整个归属域自然结束、跨域重新组合或完整外部自然分解。

## 未准入候选的逐项人工核验（第五十六批）

网页将原来只有数量的 `blocked_ownership_candidates` 展开为默认折叠的候选清单，使用既有后端结果，不改变任何准入或完成规则。

- 分别显示“来源跨越当前归属边界”和“反向确认结构属于其他归属区”。每项提供基础来源范围、输入层级和具体次级输入；M 层级不等于日线或周线周期。
- `original_known_index` 是原局部完成依据的可知时间，不是本版准入时间。所属版本的 `known_index` 是本版核验时间，不能推断为首次拒绝时间。前者可回放确认前/时刻，后者提供“回放本版核验”，均使用原始索引，不以显示日期反推。
- 高层来源 ID 必须解析为本版真实记录，层级一致、来源连续、归属范围包含且原完成时间不早于输入可知时间。基础来源 ID 校验整数和范围归属。未知原因、缺失、重复、乱序、混层或时间越界的候选提示重新分析，不提供回放按钮；这不是重新计算价格或 MACD 证明。
- 计算中禁止回放；切换版本后重新读取该版本候选，不把后来拒绝原因套回早先记录。归属合并后是否仍拒绝由重算结果决定，清单不自行修改后端资格。仍不提供具体冲突归属区/反向见证 ID，既有拒绝记录尚无这些字段，不能猜测。

仅展示当前已记录的归属类拒绝，不涵盖 MACD、端点、未确认或其他所有停止原因。没有完成整个归属域自然结束、跨域重组或外部自然分解，也不新增交易信号。

## 深层回放的未来数据隔离（第五十五批）

本批没有复现新的生产算法错误，只增加自动因果性回归，不修改现有完成条件或线上行为。

- M3/M4 确认前后分别验证：MACD 容器保留完整长度，但访问回放截点之后的值会立刻失败。标量、切片、负索引和迭代有反向测试，避免测试保护器本身失效。未来指标替换成 NaN，或将尚未确认线段的确认时间大幅延后并改写其高低范围，当前完整引擎结果仍必须逐字段一致。
- 不规则但非递减的确认时间不能使父级早于实际依赖。三层构造验证完整来源和可知时间，并在重新计算得到的实际 M3 确认点前截断，确认只剩 M2；不把固定预设日期当作判断依据。
- 两层完整归属版本路径同时覆盖 full/summary 与几何缓存：以后缀极端价格和改写指标继续运行，截点之前的所有历史详情或索引仍必须与之前一致。旧完整历史不能被之后的归属扩展或重新计算改写。

上述验证使用已确认线段和合成指标，不是原始蜡烛图全链路、实盘或任意行情证明。M3/M4 仍只覆盖单次引擎及截点，完整历史隔离例为 M2。不新增自然完成规则，不代表完成整个归属域自然结束、跨域重新组合或完整外部自然分解。

## 归属历程的真实输入交叉校验（第五十四批）

事件总数、输入计数与最终首尾一致，不足以证明中间历程正确。网页现在同时读取本版归属区的实际完成记录，不再仅凭事件自己声明的范围接受历程。

- 每个新增输入必须能唯一解析，记录层级与输入层级一致，实际基础来源连续且与本域按顺序拼接完全相同；当前归属必须对应本域，上属存在、层级递增且包含来源。重复、缺失、错层、乱序或有缺口的输入均拒绝。
- 逐事件重建前驱继承和本次新增的成员集合，实际基础来源必须连续、无重复，并准确等于事件首尾，不能用相同计数掩盖输入 ID 对调或范围夸大。向左扩展、合并时补入桥接输入仍允许；仅改名而没有新增来源不算扩展。
- 原可用时点不得晚于首次接纳事件。最终成员接纳时点应为本域形成时间与首次接纳事件时间的较晚者；不能用合并后的当前归属时间要求所有早期事件重新发生。被替代事件的临时成员数组及时释放。
- 缺少实际记录或无法交叉核验时沿用“请重新分析”提示，不补造历史；事件日期、回放入口、旧快照兼容和页面布局不变。这是结构化证据的一致性校验，不是对价格、MACD、归属证明或自然完成规则重新计算。

后端真实生成的 M2/M3/M4 合成构造及顶底镜像通过实际 TypeScript 校验函数；带日期的 full/summary 接口和确认前缀也覆盖。没有新增浏览器或实盘验收，仍未实现整体归属域自然结束、跨域重新组合和完整外部自然分解。

## 内层归属的形成、扩展与合并历程（第五十三批）

在 `nested_owners` 中新增可选 `lifecycle_events`，补足旧版只保存最终归属接纳摘要、不能还原中间变化的缺口。此字段是解释依据，不改变完成、准入、当前归属或原时间字段。

- 真实归属事件先按同刻批次共同结算，再记录形成、范围扩展或多个范围合并。事件含实际可知时点、前驱范围 ID、首尾基础来源、次级输入总数和本次新增输入 ID；同范围仅增加证明不虚造迁移。合并继承早先事件，按时间与空间顺序稳定排列。
- 只保存紧凑事件与新增输入，不逐事件复制全部结构。列表属于本版父域上下文，事件 ID 不应直接当作旧版父域中的永久 ID；需查看过去完整解释时仍用原始行情前缀回放。现有 `ownership_transfers` 保持旧字段和内容，在网页改称“当前归属接纳”，不再暗示它是完整迁移历史。
- 前端验证事件时间、前驱是否尚有效、范围包含/不交叉、输入计数及新增输入去重，最终活动范围必须准确对应本域。未知或不完整历程显示重新分析提示，不发明历史。默认折叠展示，提供确认前/时刻回放，忙碌时禁用；旧快照继续兼容。
- 相交范围合并仍只是来源管理，不是更高层中枢或自然走势完成。严格成笔、MACD 条件、信号、回测、旧 T/M 和第一版归属均不变。仍未实现整个归属域自然结束、跨域重新组合与完整外部自然分解。

## 四层内部递归的依赖验证（第五十二批）

本批不改变计算或完成规则，将内部工程递归的正例验证从 M3 扩展到 M4，并建立逐记录的自动依赖检查，而非只断言层数。

- 2192 条已确认基础线段、11061 根合成价格/MACD 数据，在单次引擎快照中形成 437 M1 → 86 M2 → 16 M3 → 1 M4。M4 来源为 1411–2035（零基编号），实际可用索引为 11055；11055 根前缀只到 M3，11056 根前缀才出现 M4。顶底镜像、非零基础编号均验证。
- 核对逐层真实子级 ID、完整来源拼接、价格起止与高低区间、层级相邻关系、原完成/归属/当前归属时点、归属父子包含、成员接纳、反向依据以及 MACD 证据。父级不得早于子级和反向依据的完成，也不得早于价格来源在当前归属中的可用时点。
- 反向依据不计入价格来源；可使用同一上属链中的未被其他内层域占用的外部依据。不能把外部依据后来合法迁入本域的时间，误作旧完成必须推迟的证明。本轮未改变此前的依据归属规则。
- 各层选中来源及有效输入集合均不重复，父级替代子级后覆盖仍守恒。末端反向确认缺失时停在 M3；无 MACD 时不产生完成结构。九类人为损坏快照用于确认测试能识别未来/提前时点、来源错配、悬空子级、自我确认、未知归属、孤立父属、指标篡改和错误自然完成标志。

这是测试侧的依赖核验，不是新增线上审计功能。构造直接从已确认线段输入，不覆盖原始蜡烛图到笔/线段的全过程；合成指标使用真实比较函数，不是行情实测。M4 本批仅验证单次引擎及确认前后快照，未验证该规模全部历史版本、HTTP 性能或整站回放，800 根 HTTP 输入上限保持不变。

**没有实现**整体归属域自然结束、跨域重新组合及完整外部自然分解；通过四层构造不能据此宣称所有行情或完整自然走势递归均已完成。

## 迟到归属的非重叠筛选（第五十一批）

第二版内部递归的候选按“可用时点、起点、终点”决定优先级。归属晚于原完成时，价格位置靠左的候选可能比右侧候选更晚可用；因此不能把“起点在上一个选中终点之前”一律当作来源重叠。

- 按原优先级逐项接纳，但只拒绝与已接纳来源区间实际相交的候选。来源包含、交叉或共享同一基础单元均属相交；只是价格端点衔接、基础单元相邻不属相交。相同可用时点仍优先较早起点、较短终点，完全同键保留原稳定顺序。
- 筛选后恢复来源空间顺序，再建立内部适配单元。保留候选不等于允许连接；来源连续、方向交替、端点一致、确认时序及相同当前归属等既有分链检查不放松。左侧较晚、右侧较早可用时，仍拆成不同输入链，不能借此提前形成父级。
- 原完成时点与较晚归属可用时点分开保存；历史版本不回填。每层选中来源仍互不重复，未选中部分继续列入未解决来源。只有第二版内部解释启用此修复，旧 T/M 与第一版归属保持原对照行为。

受控归属时序、真实完成检测的例子：左侧来源 0–4 在 125 完成，右侧域于 295 建立，310 才将左侧接纳。新版保留左侧记录并标记 310 可用；右侧四个记录仍为 295，输入分成 1+4 两条链，不生成 M2。顶底镜像与非零来源编号同样验证。受控接纳不是实盘复现，也不是新增自然完成判据。

## 摘要模式的历史内存生命周期（第五十批）

第四十九批只减少交付体积，内部仍先保留全部详细历史再投影。现在两版归属的 `summary` 模式在每个版本生成时保存独立历史索引，只让当前归属的完整记录参与后续比较、合并和输出；被替代版本的详细结构不再累计保存。所有版本仍实际计算，不能跳过历史事件或提前使用未来归属。

- 每个历史地址与 full 导出的投影逐字段相同，历史数量和顺序不变。多区并存时，当前详情仍按旧投影的创建顺序交付，`current_owner_ids` 仍保持原空间顺序；两者不能混为同一个顺序。
- 当前完整结构、过去索引及返回值保持隔离。域合并、反向见证迁移、旧时点回放、顶底镜像和三层递归均不改变结果；完整导出默认值及其历史快照保留行为不变。
- 这只减少服务器在摘要计算期间保留的历史详细对象，不是恒定内存算法。全部历史索引、归属事件、当前结构和单次扫描缓存仍随输入增长；full 模式也仍有长历史存储成本。
- 不增加共享缓存、服务器会话或用户数据写入。回放仍依赖原始行情和相同规则；索引不是可离线还原全部详情的档案。

本批不修改完成判据、严格成笔、MACD、信号或交易出口，也不宣称完成自然递归。整体归属域自然结束、跨域重新组合和完整外部自然分解仍待完成。

## 历史交付协议（第四十九批）

计算规则不变，交付模式与历史内容分开。`ChanlunResult.to_dict(ownership_history='full')` 和省略参数的 HTTP 接口继续给出原完整结果，适合审计和离线保存；默认字段保持兼容。

网页主动请求 `ownership_history=summary`，作用于个股、行业、历史回放和共同时间对比两侧的归属结果：

- `versions` 只包含 `current_owner_ids` 指向的全部当前版本，每条保留完整来源、证据、迁移与递归结构，不使用占位对象冒充详情。
- `history_format='summary_v1'` 明确改变交付形态；`history_summaries` 按原顺序保留每一个版本的 ID、确认索引/日期、基础来源范围和最高内部完成层级。历史列表必须从此字段读取，不能按当前版本数量显示历史总数。
- 点击历史项沿用原前缀回放，输入本次原始行情快照，在对应确认时点重新计算详情。使用同一规则版本和配置时与原历史版本相同；这不是保存当日数据版本，也不保证升级代码后仍得到完全相同解释。
- summary 不能单独还原被省略的历史详情，因此不是无损压缩，也不是完整离线档案。必须保留行情输入以在线重算，或选 full 导出完整记录。HTTP 回放的 800 根上限不变。
- 参数仅决定归属历史的传输形态。交易信号、严格成笔、MACD、自然完成开关、其他结果字段、权限和服务器数据写入行为均不变。不同用户之间没有共享状态或新增持久缓存。

测试覆盖全部历史索引、多个当前归属区、默认完整结果、当前详细内容与全量结果一致、历史时点重算、顶底镜像及查询参数在四条接口/对比两侧的传递。体积优化不代表完整自然走势递归已经完成，也没有减少内部历史计算量。

## 单次分析内的高层扫描复用（第四十八批）

第二版归属历史的多个版本可能含有完全相同的已确认高层输入链。只复用该链的几何归属事件、局部趋势与盘整候选，不能复用版本的身份、归属、迁移或准入决定。

- 缓存只属于当前一次分析，绑定本次原始价格和 MACD 序列。输入来自已验证的同一批基础分型对象；编号、端点身份、方向、区间高低点或确认时点变化，均重新扫描。
- 几何候选仅依赖输入自身原始区间内的价格和 MACD。相同已确认输入在较晚快照中不会读取其结束区间之后的指标；归属和版本的可知时间继续由原规则单独限制。
- 每次取出独立深拷贝的证据，再针对当版记录重新建立来源 ID、归属、接纳时间和拒绝原因。缓存不持有生成后的版本，不允许可变证据跨版本共享，也不跨查询持久化。
- 不删减、不抽样、不压缩历史版本，输出格式与全部字段保持不变。两版解释、严格成笔、原 MACD 条件与交易消费者不变。

验证已覆盖完整 429 版的 86 M1 → 16 M2 → 1 M3 顶底镜像、未复用逐字段对照、56 个完整 API 快照对照及实际接口的日期和 JSON 编码。此前“只测到三层单次引擎快照”的验证范围因此扩大，但仍是构造序列，不是实盘准确性验证。完整自然递归未完成；版本数据体积仍需单独优化，不能用省略历史换取性能。

## 反向见证归属在所有第二版入口保持一致（第四十七批）

反向确认不是本走势的价格来源，但仍是必要的完成依据。“不占来源”不能解释为“可随意借用其他归属区的见证”。第二版现有高层限制现补齐到基础内部及外部 M1 入口；旧 T/M 与第一版归属不改。

- 基础内部候选的价格来源须完全位于本区；见证可以在本区内，也可以尚未归属。见证属于另一区时拒绝。一个确认批次的所有归属先共同结算，不能因遍历顺序不同先放行再建立冲突。
- 本区自身范围不变，见证后续迁移也能改变当前资格，因此拒绝依据参与版本变化检查。旧合法快照不删改，当前版本撤回对应完成输入及其递归资格；这不是声称原历史完成从未发生。
- 归属合并后重新准入仍须满足原结构、价格及 MACD 条件，且可用时间至少为新上下文形成时点。原完成时间单独保留，不把后来合并回填到过去。
- 外部 M1 只有在价格来源与见证都未被当前归属占用时保留资格。撤回的价格来源进入 `external_unresolved_segment_indices`；见证本身仍不计入该 M1 的几何范围。
- 此处只修正当前工程准入一致性。归属域整体不是已完成自然走势，不能据此开放高层交易、跨域拼接或完整自然递归总开关。

## 逐层内部归属（第四十六批）

第一版分层归属只对基础来源建立域，内部递归再遇 M1/M2 中枢升级或扩展仍停止。新增独立第二版 `recursive_movement_ownership`，在每个递归层重复执行同一套归属及完成门槛，不替换旧出口。

- 每条来源连续、方向交替、时间合法的同层链独立检测。归属建立使用实际几何升级证明/扩展关系及接纳时点，相交范围合并只表示来源管理，不证明更高走势完成。
- 在当前域中，局部盘整/趋势候选须完整落入一个内层域或完全不与内层域重叠。跨域、部分覆盖拒绝。内部归属 ID 带父域、输入层级、基础来源范围及上下文形成时点，父子层级递增；下一轮输入按当前归属再次拆链，不能以原始来源相邻为由跨域拼接。
- 完成门槛不放松：局部中枢、价格端点、原图 A/C MACD 面积/双线及反向确认仍逐层核验。见证不占来源；可使用同一父域连续链中尚未归属其他内层域的外部见证，不允许借用另一内层域的见证。域或升级证明都不转成完成类型。
- 现有次级记录原 ID 和原完成时点保留，`current_owner_id` / `ownership_transfers` 单独表示当前放置；`current_owner_known_index` 不早于原内部可用和此次接纳。新父级的内部可用时间取原完成与所属来源归属生效的较晚者，迟来的归属不导致历史提前出现新父级。
- 版本快照继续按基础确认事件创建并冻结；第二版内部计算只使用该版本可知的来源。`nested_owners` 记录归属树、真实输入 ID、基础来源和逐项接纳。`frontier_ids` 仍由父级替代子级，同一有效来源不重复消耗；跨域拒绝另列 `blocked_ownership_candidates`，不掩饰成完成。
- 网页默认读取第二版，缺失时继续读取第一版；原 T/M 面板保持“旧解释”标识。高层域、接纳、迁移、创建时可用和当前归属可用分别显示，回放可核验它们的时间差。

验证范围：真实指标比较的 16 M1 → 1 M2 正例，以及再展开一层的 86 M1 → 16 M2 → 1 M3 引擎正例，顶底镜像、确认前后均验证。三层例的 M3 覆盖基础索引 281–405，反向次级证据到 2280 可知；不是把图表周期（日/周）当级别，也没有把高层 MACD重采样成另一个周期。

**仍保留的边界：** 所属域整体自然完成、完成单元跨域重新组合和完整外部自然分解未实现；不能把新增内部层级直接当成高层买卖点。无固定递归层数上限，但已验证的实际正例到 M3 为止；任意复杂行情和完整自然递归仍不作完成声明。所有自然完成总开关继续为假，旧信号、因子和回测消费者不改。

## 分层归属的内部工程解释（第四十五批）

用户确认后新增 `layered_internal_ownership_v1`，与原趋势 T 和混合 M 解释并存，不更改其历史字段或确认时间。

1. **归属不是完成。** 依据原链真实升级证明及扩展关系，在每个确认批次建立来源账本。相交范围合并为同一归属管理域，仅相邻不合并。该域不是新增中枢证明，更不是可向外输出的完整走势；`natural_type_complete` 和外部递归准入始终为假。
2. **局部结构在内部保留。** 第一层局部盘整/趋势仍检查自己的中枢、方向极值、MACD 和反向确认，只解除“原链已归属所以完全丢弃”的全局处理。完整来源必须在同一域内，跨域或部分重叠不接纳。基础反向线段可在域外作证据，但不占来源。
3. **完成、归属、可用三种时点。** `original_known_index` 保存原局部完成时点；`ownership_known_index` 取来源接纳与上下文合并时点的较晚者；`known_index` 是完成和归属均成立的时点。历史域合并会创建新版本，不将共同父级回填到合并前。所有同刻接纳先成批处理，版本与输入深拷贝隔离。
4. **实际递归，不自动完成。** 内部有效第一层结构适配成连续输入链，按原混合工程规则继续递归；后续层仍独立检查端点、同级结构、原图 A/C 指标和反向次级确认。缺口、方向不交替和时间逆序拆链。父级的反向确认结构也须是同域内部完成结构，不能借用邻域完成记录。
5. **有效输入来源去重。** `frontier_ids` 由父级替代其直接子级，层内不重叠；`levels` 保留子级历史证据，而不是把所有层同时投入递归。当前归属域之间不重叠，`external_m1_ids` 只保留与当前域无交集的原 M1。该清单尚不是一套新的完整外部高层分解；旧 M/T 仍为对照解释，不可与新内部记录混算。
6. **保留历史。** `versions` 记录每次来源/局部候选变化的完整快照，`previous_owner_ids` 支持来源增长和多域合并追溯。回放前缀只看当时可知记录，未来变更不修改既有版本。网页显示原完成时间、归属时间及内部可用时间，并提供确认前/时刻回放。

真实比较函数构造证据：基础来源 5–37 的五个内部 M1 形成 M2，原始索引 335 才得到第六个 M1 的反向确认；在 335 根前缀还没有父级，在 336 根前缀出现。父级 C/A 不满足时，六个子级全部保留但无父级。非零编号、顶底镜像、同刻、未来/无效后缀、归属迟于原完成和跨域合并均有回归。

**边界：** 这只打通基础归属域内部的已授权工程递归；内部再遇高层升级/扩展时仍沿用保守停止条件。尚未实现任意层级的归属迁移、整个扩展重组的自然完成、重新闭合的外部自然分解或高层交易出口。完整自然递归标志继续为假。版本完整快照会随长历史增长，未来可做无损存储压缩，不得以截断历史换取性能。

## 重组分区的历史工程完成依据（第四十四批）

混合递归已能确认工程盘整/趋势，但版本重组审计只检查端点及反向线段，未关联已有的工程完成记录。本批在 API 导出时增加独立衔接，不改变重组搜索、版本、完成选择或自然完成判据。

## 升级中枢的完整成员归属保护（第四十二批）

复现并修复第四十批工程趋势入口的遗漏：全链升级过滤只检查九成员证明的固定来源区间；一个已升级中枢继续延伸后，局部搜索可以从第十个及以后的成员重新起算，避开九成员区间，错误地把已升级中枢的延伸尾部配成未升级同级趋势。

- 新增 `promoted_member_times`，对每个具有实际几何升级证明的中枢，逐个读取完整接纳账本。每个成员的保护生效时间为 `max(升级证明可知时间, 该成员实际接纳时间)`。不是数够九个就升级，也不是以最终成员集合追溯封禁历史。
- 升级前的早期成员不能提前受保护；升级后的新成员必须等真正接纳才受保护。待回试离开单元、成功退出的外部离开/回试单元不属于该中枢，不能因相邻或充当确认依据而被错误占用。
- 工程趋势局部候选在实际确认时，只要复用当时已属于原链升级中枢的成员，就拒绝作为新同级完整趋势。基础线段层和后续工程趋势层共用这个入口。此项仍是保守级别策略，不声称高级别中枢内部不存在任何低层结构。
- 规则版本改为 `approved_macd_reverse_v2`，增加 `promotion_scope=all_admitted_members_at_candidate_confirmation`。不改严格成笔、MACD 数值条件、原基础结构信号，也不改变冻结的九成员升级证明本身。

构造反例：原链第 0–13 个单元属于同一个已升级中枢，但九成员证明仅覆盖 0–8；旧局部搜索在 10–18 上生成完成趋势，实际确认位置 195。新规则识别其中 10–13 的升级归属，拒绝这个错误候选。顶/底镜像和非零编号都复现并修复。另有正例从中枢外部离开单元 14 开始，独立两中枢趋势在 14–22 完成，仍允许通过，不封禁全部后续历史。

本轮修复了实际递归准入错误，未新增盘整结束或扩展重组完成判据，完整自然递归仍未完成。

## 已授权的工程趋势完成与真实递归（第四十批）

用户确认采用“同级结构成立＋对应区间 MACD 面积及双线背驰＋反向次级结构确认”作为趋势结束的工程判据。本批新增独立研究出口 `engineering_trend_hierarchy`，没有把既有重组候选的 `natural_type_complete` 改成真，也没有修改基础买卖点、严格成笔或 MACD 参数。

- 一条趋势须有至少两个同向、外围严格分离且未升级的中枢，完整来源连续，首尾为该方向区间极值。A 为末中枢前的同向进入单元，C 为同向离开单元；沿用原 MACD 比较函数，检查价格创新极值、同色柱面积减弱和 DIF/DEA 双线向零轴靠近。
- MACD **不是**把 T2 当另一时间周期重新计算，而是沿用原图指标序列，按本层 A/C 的完整原始 K 线区间计量。此口径在 API 和网页均明确标注。它是约定的工程过滤，不是原著唯一定义或实盘收益保证。

## 基础趋势信号的同级别准入（第三十九批）

修复基础信号入口与高层升级证明之间的遗漏：旧入口只检查相邻两中枢外围分离以及 MACD 条件，没有检查其中一个中枢是否已获得延伸升级证明。因此可将一个已升级中枢与一个普通基础中枢配成基础趋势，生成一买/一卖并派生二买/二卖。

- `centre_extension_proof` 共用于既有延伸树和信号扫描，仍检查连续已接纳来源、三个子区间及其交集；不是只数够九条。待回试的离开段尚未接纳时不能升级。信号扫描直接使用当时的活跃中枢，不重建已扫描生命周期。
- 基础趋势一类信号要求配对的两个中枢在信号确认时都没有已确认升级证明。前中枢或当前中枢任一已升级，均不输出该基础一类信号，也不把这次被拒绝的趋势判断改名为盘整背驰来绕过检查。
- 二类信号沿用其对应一类信号的两个中枢来源，并在二类确认时重新检查级别。如果一类信号早于升级，其历史记录保留；若二类在升级时或之后才确认，则不按旧基础趋势来源继续生成二类。
- 判定比较证明的实际 `known_index` 与信号确认时刻。扫描末统一处理同一时刻的证据，防止先循环到一类、后循环到同刻升级而漏拦；后来时刻的升级不能倒删此前有效信号。拒收后缀、未来确认与不完整原始链均不能提供升级依据。
- 独立基础三类核心离开/回试、独立盘整力度参考及指标背离保持原规则；它们并不因此成为高级别信号或自然完成证明。本门槛是当前尚未完成混合层级递归时的保守基础趋势准入，不声称高层中枢内部不存在任何低层买卖点。
- 图表、因子和回测继续消费同一结构信号出口。新增元数据 `trend_signal_level_policy=unpromoted_centres_at_confirmation_v1`，其余信号来源标识不变。算法版本变化会有意减少原先级别混用的一二类信号，不承诺与修复前信号集合完全相同。

新增 19 项回归，包括双侧、两种升级来源、非零编号、同刻批次、迟到升级、九段待接纳、断链、实际 MACD 门槛以及因子和策略出口。另对 400 个随机/镜像构造前缀，以修改前延伸树和信号为独立参照，证明字段完全一致，只有符合本门槛的事件被过滤。随机结构门槛对照为隔离级别问题放行了 MACD；不作实盘有效性或收益验证。自然完成、高层生命周期与完整递归仍未完成。

- 保留旧切片搜索作为独立对照和固定形成记录使用；本批不改变 API 字段、版本编号、日期、信号或网页布局。内存复用只限一次调用，空间随实际访问区间和快照增长，未声称内存有固定上界或所有行情都会提速。

验证新增 16 项测试，覆盖全子区间乱序、上下镜像、非零编号、历史确认前后、同刻批次、升级优先、断链、未确认尾部、未来锚点、返回值隔离和每一起点不重扫/不越过请求终点。与修改前副本比对 178 个完整 API 快照逐项相同；另对 120/240/360/600 条构造线段的完整版本输出比较一致。

## 多中枢趋势子走势候选（第三十七批）

- 搜索先保留原单中枢模型的端点一致方案；若无一致方案，再尝试允许多中枢的搜索。后者只有端点一致时才替代原几何冲突方案；如果两者都不一致则保留原几何回退；原模型完全无解时允许新的几何候选继续接受审计。这是明确的确定性搜索顺序，不是原文的唯一分解定理。

- 每个起点滚动推进基础中枢生命周期，分离一旦被后续扩展打破、或出现九段接纳就停止后续搜索，但保留此前有效的独立快照。区间仍保留所有连接段，A/B/C 来源不重叠且连续，端点与区间极值校验、三分区交集及既有切点排序保持。
- 新搜索选中的分区附 `component_kind` 和 `centre_chain`，列出各中枢初始来源、形成时刻、固定核心和已接纳外围。兼容字段 `zd/zg` 与 `seed_segment_indices` 仍指首个内部中枢，不能解释为整个趋势只有一个核心；候选高级核心仍按三个子区间完整范围计算。网页显示趋势候选和中枢数量，内部中枢依据默认收起。
- 历史版本按同一 v3 规则和可见前缀重建，不能用未来形成或后续扩展的中枢补写旧快照。v1/v2 旧结果继续可读；换规则可能改变研究分区和版本编号，修改前结果可由恢复副本还原，不承诺跨算法规则版本编号不变。

## 完成依据绑定重组版本（第三十六批）

原 `expansion_regrouping.completion_audits` 仍只核验初次形成的固定分区。动态重组后不能拿旧分区的证据充当新分区的完成证据；初次没有分区而后来得到切分的候选，也不能因此一直没有完成核验。

- 每个重组版本新增 `completion_audit`，使用 `interpretation_id` 绑定版本编号，完整匹配该版每个分区的来源、方向极值、首条已确认反向基础线段及其 A/B/C 内外归属。复用原完成审计规则，不新增或放松自然完成条件。
- 历史版本仅用该版 `known_index` 以前及当时的已确认来源生成依据。同一确认时刻多段仍原子处理。当前案例另有截至当前已确认前缀的审计：后续反向线段出现时可更新当前审计，但不得更改历史版本的当时依据，也不凭此制造一个新切分版本。
- 当前没有分区、已有高层证明优先、保留前缀归属待定、来源覆盖冲突或完整证明跨归属边界，分别列出阻塞原因。高层优先时不继续审计之前的基础 A/B/C，空分区不能以“没有失败项”为由被视为完成。全部仍保留 `same_level_completion_unproven`。
- API 为当前及历史审计分别补充截止日期、反向线段极值和确认日期。反向基础线段的确认可能早于本版形成；回放其确认时刻仍使用当时可见的解释，不表示本版已经在该时刻形成。
- 网页当前及历史版本均有默认收起的“本版完成依据”。对版本、来源、时间、极值、方向、反向线段归属及完成标记进行匹配校验；旧数据或错配显示重新分析提示，不退回使用初次形成的审计。

构造案例：`expansion:6:15` 初次没有可用切分，205 时形成移动起点后的第三版，215 时形成第四版。第四版 C 为编号 19–23，215 时没有已确认反向线段；220 时编号 24 确认，当前审计补上该证据，但第四版形成时的历史审计仍没有它。此为构造核验，不对应真实股票。

本批没有保留试作的自动扩围模块：现有合法候选起点是基础中枢初始来源，延伸证明属于各自中枢，正常输入不会出现此前假设的跨起点裁切。自然类型完成与高层实际递归组合仍未实现；严格成笔、MACD、结构信号和候选选择不变。

## 混合层级来源覆盖（第三十五批）

新增 `mixed_source_cover`，规则 `indivisible_source_cover_v1`。这是高层证明与基础线段之间的无损来源表示，不是已完成自然走势的递归输入。

- 对每个候选，从原起点到当前可知尾部建立完整来源序列，分别记录保留前缀、候选来源或 A/B/C 分区、待定尾部。基础线段按相同临时归属分组，不命名为已完成走势。
- 只采用截至该快照已知的延伸证明。已知父证明整体替代其覆盖的低层子证明，避免重复占用；尚未确认的父证明不能遮盖已经可见的子证明。每个来源在有效覆盖序列中恰好出现一次。
- 高层证明保持不可分割。跨越前缀、候选分区或待定尾部边界时，仍保留一个完整证明块，并列出内部临时归属，标记需要整体重组，不顺着旧分区切碎证明。
- 若证明跨出整个候选来源窗口，或存在非嵌套的重叠证明，覆盖状态为 blocked，保留请求来源与冲突证明的原始来源范围，不生成伪造的基础线段替代序列。后续需要扩大研究范围或重新确定整体归属；本批不自动越过原候选范围。
- 每个历史版本绑定自身确认时刻的来源覆盖；当前案例另有覆盖快照，尾部可能继续增长而不生成新的重组版本。`as_of_index/date` 与 `interpretation_id` 明确区分快照时间和解释版本时间，防止后来来源被回填到旧解释中。
- API 添加证明和覆盖的日期；前端校验解释编号、可见时间、连续来源、层级跨度、分组归属及禁止完成标记。默认折叠显示来源，沿用确认前/时刻回放；缺失或错配不冒充已核验。

自然完成和递归准入仍为 false。原分区选择、历史版本编号、确认时刻、严格成笔、MACD 和交易信号不变。本批没有实现自然类型完成、高层级生命周期或混合层级的真正递归组合。

## 受约束的起点重组与前缀保留（第三十四批）

本批核对后半部分第 99 课结合律案例。原文允许为后续中枢拆开前走势，但不规定唯一的程序切分排序。本实现新增的是**候选起点重组**，不是声称已经实现原文的完整趋势尾部拆分或自然完成判定。

- 当前解释升级为 `causal_regrouping_versions_v2`。除原起点外，只允许在原候选左中枢的已接纳成员中选择起点，不能一路向后滑到无关中枢来制造成功。原候选需两中枢退出后才进入解释通道，锚定成员此时已固定。
- 每个可见终点先试原起点；原起点已端点一致则不裁掉前缀，否则按从早到晚检查锚定起点，只接受端点一致的移动方案。没有一致方案时仍保留原起点的几何回退。跨终点继续采用“端点一致优先、同类更晚终点优先”的规则；同一个终点内优先保留更多来源。这是确定性的保守实现选择，不是原文唯一算法。
- `retained_prefix_segment_indices` 完整保留从原起点到当前起点之前的来源，`prefix_role=unresolved_prior_sources`。前缀、当前切分来源、待归属尾部按原顺序覆盖整个当前来源窗口，不能遗漏或重叠。不把前缀直接命名为已完成盘整/趋势，不跨候选强行统一归属。
- 起点改变时记录 `start_change` 的前后起点、本版移出及重新纳入的来源编号；比较的是上一可见版本，而非同一确认时刻内不可见的中间状态。可知时间仍是支持本次解释的真实确认时刻，不回填到新起点的极值位置。
- 高层延伸证明的优先检查仍覆盖原起点到当前来源终点，包括保留前缀。不能通过移开起点绕过已知升级证明；真正只在待归属尾部的无关证明仍不撤销旧解释。
- 前端兼容 v1 无前缀的旧结果；对 v2 校验来源连续性、锚定范围、前缀角色、前后起点和移出/重新纳入记录。不匹配时提示重新分析，不显示为已核验。沿用原折叠历史布局，当前和旧版本分别显示保留前缀。

构造案例：原来源从编号 6（网页线段 7）开始，在确认索引 200 仅能得到有端点冲突的切分；205 时可改从编号 11（网页线段 12）开始，得到 3/5/3 的向下/向上/向下分区，候选交集 90–98。编号 6–10（网页线段 7–11）保留待归属。确认前回放没有这个调整；镜像、非零编号与断链测试均覆盖。案例不对应真实股票或交易建议。

仍未实现：不限锚定范围的全局自然分解、前缀的自然完成证据、完整趋势末端拆分、混合层级递归闭包和高层级生命周期。所有自然完成与交易准入仍为 false，原成笔、MACD、基础结构信号及确认时刻不变。

## 当前解释与历史解释分离（第三十三批）

2026-09-29 用户接受：当前高层结构可以随新证据重组，历史核验保留当时解释，不能倒填原信号确认时刻。本批先实现跨中枢候选的**动态终点搜索与版本记录**，不是完整自然走势递归。

- `expansion_regrouping` 继续保存初次形成的固定窗口，原有候选、审计和图表定位不变。新增 `regrouping_versions` 为独立的当前解释视图，网页分别标示两者，不覆盖旧候选。

- 版本按同一规则、同一行情/已确认线段前缀确定性重建；回放截止前看不到后续版本。本批不新增持久化行情版本库，不能声称保留了行情修订前或规则升级前的原始快照。
- 现有基础归属、严格成笔价格、MACD 门槛、指标颜色和原信号链不变。版本记录不输入策略/雷达/回测；所有自然完成及递归交易准入仍为 false。

## 已实现的可证明子路径

来源：用户提供课程前半部分第 33 课九段延伸及结合律说明；后半部分第 99 课要求优先保证升级中枢的成立。

`extension_hierarchy` 是**延伸重组证明**，不是完整自然走势分解器。

- 基础输入仅为连续、已确认的线段。它们在此定义最小输入层，不代表日线/周线级别。
- 先沿用基础中枢生命周期，只有已纳入的组成线段参与计数。等待首次回试的离开段不参与；失败回试后才纳入，并记录实际可知时间。
- 同一个中枢内至少九条连续组成线段，才尝试三级分组证明。每组三条的价格区间必须有正宽度交集；再验证三个完整子区间的交集。不是“数量达到九就算成立”。
- 更高层递归重复该证明，当前保守路径需要 27、81……条同一基础延伸内的线段。只验证这条充分条件路径，**不把它宣称为所有高级别中枢的必要条件**。
- 每个节点记录全部来源线段、三个子区间、固定交集、外围、端点和可知时间。重复出现的来源证明保留相同时间，不因更高父节点形成而推迟。
- 按输入前缀计算最早可知时间；不能将最终成员列表用于回填历史。根节点形成证明固定，后续加入不重写。
- 实现以中枢接纳记录直接保存上述时间，不再对每个历史前缀重复运行完整中枢识别。初始三段在共同形成中枢时接纳，普通延伸在当段确认时接纳，失败离开段在回试确认时接纳。接纳记录只追加、不可倒填，并以独立历史前缀重算验证等价性。
- 重组产生的子区间不是自然走势终结信号，`natural_type_complete=false`；不送入交易策略生成新信号。

## 仍然未实现，不得标记完成

1. 自然走势类型在延伸、趋势延续、反向形成之间的起止与完成证据。
2. 两个不同基础中枢外围重叠后的完整重组：外围交集不是新中枢核心，两个基础中枢退出也不能直接当作三个已完成次级别类型。
3. 跨独立中枢、连接段和混合低级别结构的递归组合，以及更高级别中枢自身的离开/回试生命周期。
4. 上述完整结构到策略、雷达和回测的逐时点传播。

因此 `structure_metadata.recursive_levels_ready` 仍为 false，仅新增 `extension_regrouping_ready=true`。
界面明确展示该边界。完成第 1–3 项并验收前，不得把这一子路径描述为“高层级缠论递归已全部完成”。

## 跨中枢重组候选搜索（第十七批）

新增 API `expansion_regrouping`，独立于已证明的延伸树，不自动绘为高级别中枢。

- 准入仅限相邻基础中枢核心分离且外围相交/触及。两个中枢均退出前只记录等待状态，不生成切分。
- 搜索从前中枢初始线段到后中枢退出回试段的连续来源区间，包含连接段；这是结合律下的替代重组，不改写原归属分解。
- 每个分区至少三条确认线段、恰有一个未达到九段延伸的基础中枢。各分区起末线段方向与净方向一致，三分区方向交替；三个完整分区的价格范围须有正宽度交集。
- 第二十二批起，优先选择三个分区的起止点均通过方向极值校验的候选；同一优先级内按第一切点、第二切点从早到晚确定。如果所有几何切分均有端点冲突，保留首个几何候选及其冲突依据；完全没有几何切分时才输出无候选。不声称这是原文唯一自然划分，也不用外围交集充当核心。
- 已九段升级的输入保留为需要高层级输入，避免把它重新当成普通基础类型。
- 输出 `candidate_core`（候选核心）与 `envelope_overlap`（旧外围交集）两个独立字段。成熟候选记录实际可知时间；各分区记录来源、种子、方向、极值、价格范围及可知时间。
- 分区仍为自然完成**待验证**状态；`higher_level_confirmed=false`、`natural_type_complete=false`。这一搜索不能代替自然走势完成判定，不能输入高层级策略。

## 候选分区完成依据审计（第十八批）

`expansion_regrouping.completion_audits` 与固定的候选形成记录独立：

- 用保守的“方向极值包围”条件检查起止点。向上分区的起点/终点分别对照全区间最低/最高，向下反之；这是当前实现的保守准入条件，不声称是原文全部重组方式的必要条件。
- 单独记录起点、终点冲突及预期极值。原候选核心仍仅是几何重叠结果，审计不把它改名为已确认中枢。
- 查看分区之后的首条已确认反向基础线段，并记录实际可知序号及日期。未确认、越界或断链后的线段不参与。此证据只证明次级别转折，不证明同级别走势完成。
- `as_of_index/date` 是本次审计截止；`known_index/date` 仍是原候选形成时刻，不能混用。随着新线段确认，审计可更新，但成熟候选不会被覆盖。
- 所有分区仍包含 `same_level_completion_unproven`，`eligible_for_recursive_input=false`。没有通过把布尔值改成 true 来伪造自然完成。

当前样例的第二分区起点 115 低于内部最高 116，第三分区终点 110 低于内部最高 113，均不满足该保守准入。后中枢回试结束只是第十七批几何搜索的固定窗口终点，不能默认当作自然走势终点。后续需要结合后续结构重新研究自然边界，而不是固定该切分后强制确认。

## 跨中枢切分的端点优先选择（第二十二批）

规则版本为 `cross_centre_three_range_search_v2`。`partition_selection` 为：

- `endpoint_consistent_preferred`：六个分区起止端点均与方向极值一致，搜索与审计共用同一浮点容差。
- `geometric_fallback_with_conflicts`：穷举同一来源区间仍无端点一致的几何切分，保留原首个切分作为问题依据，不丢失冲突证据。
- `null`：等待中枢退出、需要高层级输入，或没有三段几何切分。

构造样例中，来源线段 15–25 的首个 3/5/3 切分，其中段从 73 开始却含最低 63；继续搜索可得到 5/3/3：98→63、63→82、82→75，六个端点均符合方向极值，候选核心为 75–82。该选择只使用两中枢退出时已确认的固定来源区间，不等待未来线段筛选，不改变候选可知时间；相同历史数据及规则版本下，后续输入不覆盖成熟候选。规则版本升级可以改变旧候选切分，不应被误解为同版本历史回填。

优选通过只解决端点冲突，不证明自然走势完成。三个分区仍为 `natural_type_complete=false`，审计仍含 `same_level_completion_unproven`，不会送入递归交易或新增买卖点。

## 接纳记录与升级回放（第二十一批）

基础中枢的 `member_admissions` 逐条记录原始线段编号、线段自身确认时间、中枢接纳时间及原因。待回试的离开段不在记录中；成功离开后的连接段和回试段也不补入旧中枢。升级证明仅取本次来源范围内的记录，已形成证明不因后续接纳而变化。

根证明的同名字段额外提供两个时间的显示日期。网页“来源接纳时间”默认折叠，失败离开后纳入的段可回放到接纳前一根及接纳时刻。构造样例第九段自身确认序号为 140，回试确认及接纳序号为 145，升级时刻仍为 145，不能提前到 140。

这是对已实现延伸证明的可追溯性和执行效率优化，不增加自然走势完成证据，不改变 `natural_type_recursion_ready=false`。

## 基础生命周期逐段推进（第二十三批）

`iter_structural_steps` 在一次计算内按已确认线段顺序推进形成、延伸、离开及回试状态；批量中枢接口和结构信号共用这一流程。无正宽度初始交集时滚动寻找三段种子；成功退出后仅把回试段作为下一种子的开端，不重复纳入连接段。失败离开在回试确认时纳入，回试本身仍可能立即成为反向离开。

迭代器给出的中枢对象是内部动态状态，不是历史快照。信号在推进下一条线段前复制当时的成员及价格依据；不得保存动态对象后再读取其未来状态来补写旧信号。已退出的前中枢不再变动。二类信号仅在一类信号之后的首个完成回试编号到达时检查，不扫描或重复匹配更晚的回试。

输入确认、断链、截止时刻、边界触及和原信号规则全部保持。此为单次调用内的逐段处理，不是跨请求缓存，也不是把基础线段转换成已完成的高层级自然走势。历史行情被修订后仍重新计算；完整高层生命周期和自然走势递归尚未实现。

## 原始极值锚点与来源编号（第二十四批）

图表端点日期、结构信号的 MACD 比较区间、基础分解区间、延伸证明及跨中枢候选统一使用 `anchors`。在分型中央合并 K 线所含的原始 K 线中，按顶/底类型匹配 high/low，沿用图表与递归证明的容差 `max(1e-8, abs(price) * 1e-9)`，同值多次出现时取最后一次。没有原始来源或没有匹配值时，沿用合并 K 线末尾序号及日期作为回退。

原结构背驰定位使用独立的 `1e-6` 容差，可能把较晚的相近价格误当作同一极值；统一后此边界下的标记及 MACD 窗口可能修正，但不放宽/收紧背驰本身的价格和力度门槛。原分解直接使用合并区间末尾索引，现改用统一原始极值；API 补充同口径的 start_date/end_date。

极值位置不等于确认时间。known/confirmed 索引仍使用原确认依据，不能因端点提前而把信号提前。中枢序列化根据线段的实际 index 查找来源，不能把来源编号当成数组位置；非零起始编号不会再造成错位或越界。上述定位修正不证明自然走势完成，也不解锁高层递归交易。

## 网页跨中枢核验（第二十五批）

“缠论结构”的结构信息区新增默认折叠的“跨中枢候选核验”，读取 `expansion_regrouping`，不改变后台候选算法。显示相邻中枢、完整来源、旧外围交集与候选核心、优选/冲突回退原因，以及 A/B/C 三个连续重组分区。A/B/C 是重组分区，不是按 MACD 柱色分出的波段。

候选初次可知时间与当前完成审计截止日期分开显示。每个分区展示方向极值冲突、第一条反向基础线段和仍缺少的自然完成证据；审计按 candidate_id 关联，分区还必须匹配 part_index 与完整原始线段编号列表，不按返回数组位置套用。未知状态、旧字段缺失或依据不匹配均提示待核验，不显示通过。

复用原始 K 线索引驱动的确认前/时刻回放入口，计算中禁用，缺失/无效目标不提供按钮。首条反向基础线段只证明基础转折，不能表示同级别完成。本区不将候选自动绘成高级别中枢，不生成新交易信号；完整递归仍未完成。

## 重组候选的图表定位（第二十六批）

“定位重组区间”将候选三个分区的原始 K 线起止位置同步标在价格、成交量及 MACD 图中。覆盖层明确命名“重组 A/B/C”，不是 MACD 红绿柱波段，也不是已确认高级别中枢。端点冲突的几何回退候选仍可定位以供核验，不因此获得自然完成资格。

只允许定位当前结果中已有三段切分且可知时间落在当前可见历史内的候选。三个分区的来源必须与完整候选来源逐项一致、连续且无重复，每段至少三个来源；原始起止索引必须连续、合法且在可见数据内，各分区可知时间不得晚于候选可知时间。缺字段或验证失败时不提供定位入口。

点击只传递候选身份，父页面按当前结果重新查找和校验，不持有旧结果对象进行定位。计算中禁用；定位只调整图表视野，不改变回放时刻。复用既有视野记忆，清除定位后恢复定位前缩放；结果快照变化时同步清除旧覆盖层，不把旧视野恢复到新结果。行业图不套用个股候选区间。

本轮不修改后端结构、信号或递归准入，不改变严格成笔价格及指标颜色。自然走势完成、高层生命周期与完整递归仍未完成。

## 递归入口的双时间轴校验（第二十七批）

`confirmed_segment_prefix` 不再只依靠合并 K 线序号和价格判断连续。线段来源编号、合并 K 线序号及末尾原始序号必须是非负整数（排除布尔值），原始极值锚点也必须为合法序号，并满足：起点极值 ≤ 起点合并末尾 < 终点极值 ≤ 终点合并末尾 ≤ 线段确认时刻。传入历史截止时，确认时刻还必须在可见范围内。

相邻线段除了合并序号与价格一致，还要求共用端点的原始极值位置、合并末尾序号一致。按值核对而非 Python 对象身份，因此独立复制但相同的端点仍然合法。无来源 K 线或没有匹配极值时沿用统一锚点函数的末尾回退，不强制每个极值都落在合并末尾。

任一检查失败时保留此前有效前缀，停止接纳后缀，不跳过错误凑足 9/27/81 段。基础中枢、归属分解、延伸升级、跨中枢候选和结构信号共用该入口。该检查针对原始位置自相矛盾的内部结构输入，不代表已经重验全部来源 OHLC 数据或日历日期；上游行情规范仍由输入层负责。

构造反例中，9 段确认时刻截至 140，但末段原始极值被错误标为 999，旧入口仍生成 end_index=999 的升级证明；修正后只接受前 8 段，不生成该证明。已有合法前缀的候选与信号保持，不修改成笔价格、MACD 门槛或自然走势完成条件。

## 跨中枢候选的等价搜索加速（第二十八批）

候选搜索仍在两中枢退出时确定的固定来源窗口内进行，规则保持 `cross_centre_three_range_search_v2`，端点一致优先、同类最早切点、无一致解时保留首个几何回退均不改变。

对超过 24 段的窗口，每个需要使用的起点仅推进一次基础生命周期，逐前缀保存独立的几何摘要；区间极值滚动维护，不反复重建相互重叠的整段中枢。形成第二个中枢或首个中枢已接纳九段后，该起点的更长范围均不符合原单中枢条件，可以停止，但不得删除此前已合格的短前缀。摘要不得引用以后会变化的中枢对象。

24 段及以内继续使用轻量的按需切片路径，避免常见短候选因预计算而变慢。两条路径共享摘要字段生成，只在选出结果时展开全部来源编号。缓存限于一次搜索调用，不跨股票、历史前缀或数据修订复用。完整来源在公共入口先按共享时间轴规则校验，不允许按独立后缀跳过断点。

本次不引入新的自然完成依据，不改变候选或确认日期，不增加高层买卖点。自然走势完成、高层生命周期及完整递归仍未完成。

## 嵌套证明的接纳依据与外部依赖（第二十九批）

基础中枢接纳记录增加 `admission_segment_index`，明确是哪条线段的确认触发接纳：初始三段对应第三条种子，普通延伸对应自身，失败离开对应其首个回试。该编号在生命周期推进时直接记录，不通过确认时间反查；多段同一时刻确认时仍能区分实际依据。

延伸证明每一层均输出本节点来源对应的 `member_admissions`，不再仅根节点提供。所有层沿用同一个基础中枢的实际接纳记录，不把子分组当成已经结束的独立自然走势。每行单独复制，父子节点与不同根证明之间不共享可变字典；节点可知时间仍为本节点来源接纳时间的最大值，原几何与时刻不变。

组成来源与确认依赖必须分开：例如来源编号 0–8 的九段证明，其第九段离开后需等编号 9 回试确认才接纳。编号 9 是分组外确认依据，不因此加入 `source_segment_indices`，也不计入九段数量、外围或核心。同一证明出现在更高层的子节点时仍保持相同依据和可知时间。

网页各层默认折叠，支持展开来源接纳记录，并回放到该项证明可知前一根/时刻。分组外依据明确标注“仅作确认依据”，旧数据缺字段显示未提供，不按序号或时间猜测；没有嵌套记录则不伪造列表。仍不代表自然走势完成，不生成高级别买卖点。

## 跨中枢反向依据的来源归属（第三十批）

完成审计增加 `opposite_evidence`：首条已确认反向基础线段的真实编号、方向、原始起止索引/价格、确认索引及 `source_part_index`。API 对起止和确认分别补充日期，沿用统一极值锚点，不以合并末尾代替真实极值。尚未确认或断链之后不存在此证据，后续线段不替代首条反向线段。

`source_part_index` 按完整来源编号关联，而不是以线段编号当数组位置。A 的首条反向线段属于 B，B 的属于 C，C 的首条反向线段位于固定候选来源之后（该字段为 null）。候选内复用的基础线段不能称作额外独立的同级别完成依据；候选外的反向线段不补入固定 A/B/C 的来源、核心或初次可知时刻。

网页显示反向线段的归属和两位小数起止价格，原始极值日期与确认日期分开。新增明细须匹配审计编号/确认时刻、分区终点、后继编号、反向方向及当前可见范围，归属还需与候选来源一致。旧数据或错配明细明确提示未提供/不匹配，不猜测归属。日期块在窄屏整体换行，不拆散日期和时分。

该改动补充可核验信息，不修改固定切分、完成审计旧状态及阻塞原因；同级别完成仍待证明，递归交易准入仍为 false。

## 核验依据的导出隔离（第三十一批）

`ChanlunResult.to_dict()` 输出独立的可序列化快照。已确认线段、未完成线段、买卖点、背驰的 `evidence` 深层复制；中枢关系历史在补充日期时也保留深层隔离，不能用浅复制覆盖 `asdict` 已建立的独立列表。调用方修改导出结果中的来源编号、特征区间或附加说明，不得影响分析对象、另一次导出或同次导出的其他证据分支。

结构信号转换为图表买卖点时，来源列表和嵌套依据也独立复制。修改图表买卖点的核验依据不回写权威结构信号，反向修改原信号依据也不改变已经转换的证据。仅复制小型依据树，不深拷贝完整行情/笔/线段对象图；内部买卖点对原几何对象的引用仍按既有设计共享，分析结果对象本身并非全局只读对象。

本批解决内部 Python 调用方的共享引用风险，不表示浏览器编辑 JSON 能直接修改服务器内存。没有修改任何判定门槛、来源编号、确认时间、递归范围或网页布局；自然走势完成与完整高层递归依然待实现。

## 按消费进度校验线段（第三十二批）

基础生命周期改为先校验当前线段、再推进当前状态，不在第一次输出前预先扫描整个后缀。跨中枢分区搜索一旦因第二个中枢形成或九段接纳而淘汰当前起点，随即停止后续校验；不读取对该分区已无用途的剩余来源。

完整批量入口 `confirmed_segment_prefix` 仍返回独立的列表容器、保留原线段引用，并校验完整的可接纳前缀；它和逐段迭代共用同一个校验实现。原始/合并时间轴、价格、方向、编号连续性、确认顺序与截止边界全部不变。遇到第一个无效链接即停，不再请求其后输入，更不能跳过断点拼凑递归来源。

该迭代只用于单次计算，不是跨请求增量缓存。迭代期间输入线段不得被调用方修改；中枢对象仍是内部动态状态，消费者需要在下一步之前复制所需历史依据。多个迭代实例独立，不共享校验位置或中枢状态。未新增自然完成依据或高层买卖点。
