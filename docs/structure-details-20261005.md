# 缠论工具栏、背离右键详情与股票名称（本地完成，未部署）

## 范围

- 工具栏统一 28px 控件高度和垂直居中。图例与历史开关分组，窄屏自然换行；不再由两种不同高度的内嵌行混排。
- “盘整进行中”图标改为对称圆角细框＋小时钟 SVG，去掉小尺寸 CSS 虚线边框。没有修改图中盘整区域的计算或状态含义。
- 盘整与背离共享 StructureInfoPopover，单图只打开一个详情面板。右键背离／背驰标记显示类型、生命周期、极值／对照／首次提示／实际确认／失效时间、消息与可展开依据。
- 覆盖当前可见的双线、标准波段、非标准波段、特殊波段、笔、盘整、趋势背驰；候选、确认及开启历史后的失效记录都保留独立来源。
- 命中读取实际 markPoint 坐标与堆叠偏移，标记优先于盘整矩形；未命中不拦截原生右键菜单。提供触屏／键盘入口，支持外部点击与 Esc 关闭。
- 股票名称缺失原因：targetTitle 只读取 target.name，但个股 target 原来只有 kind/code/market，未接入股票名称。现复用响应式 stockDisplayName，名称通过现有查询历史补全；查询失败时仍仅显示代码，不猜测名称。指数和板块保留原有名称机制。
- 按 frontend-skill、sidebar-dialog-ux 使用克制的间距、统一控件与非模态短详情，避免新增常驻栏。
