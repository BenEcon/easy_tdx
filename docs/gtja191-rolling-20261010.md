## 来源、差异与数值边界

沿用首批记录的 DolphinDB 固定提交 `43ace2cc4b81d048864ec2e40c25728d5d464e05`（Apache-2.0）与 2017-06-15 原报告。原报告第 11—17 页及算子页的视觉复核记录属于本批公式实施前的核查；原 PDF 不再分发，许可、来源 SHA、归属见 `gtja191-foundation-20261010.md` 与 `NOTICE`。没有复制 BenEcon 专有实现。

- 021 按原报告先求均价，不采用参考模块遗漏均价的写法。斜率有截距、不除以价格；021 与 147 设成同窗口时作为同义配置拒绝重复。
- 127 原表未写外层均值窗口，明确采用默认 12、改参时同 w；MAX 按滚动峰值解释。该歧义已写入元数据，不能宣称与参考软件逐位等价。
- 极值距离从 0 起算，并列取最近；原报告 LOWDAY 释义存在与 HIGHday 相同的“最大”字样，本实现按低点名称及参考模块语义取最小值，作为明确适配。
- 086 的阈值 0.25 是价格单位。边界手算发现二进制消减会把恰好 0 或 0.25 的变化送入错误分支，现用输入价格往返十进制比较，不引入任意容差。049—051、128 的价格和方向同样避免相等值被判为涨跌。
- 139、191 使用居中、缩放 Pearson，常数序列留空；OLS 先减价格基准，避免大价格偏移压掉微小变化。
- 158 的两项同一平滑量在代数上相消，因此不保留无关递归状态或伪造 15 根预热。171 先计算价格比再求幂，避免直接五次幂溢出；收盘等于最高时分母为零，留空。
- 128 原式含 U/D，没有下跌资金流时不擅自取极限 100。旧通用测试“预热后全部非空”在这里不成立，已改成逐窗口独立核对负向资金流与空值日期，仍保留完整因果前缀检查。

## 使用与恢复

进入「量化研究 → 因子序列」，因子库选择「GTJA191 · 已实现价量」，搜索编号，选择例如 021／086／191 后计算；在折叠参数中修改窗口，再计算以生成新结果。使用保存／导出保留原值；只读原档不取数，只有显式重算会产生新版本。示例仅说明功能，不构成投资推荐。

改前 `source-before-gtja-rolling.tar.gz` 保存 GTJA 实现、独立测试、证据工具／测试及账本。此后修改的通用研究测试，其改前版本在上一批 `source-after-gtja-foundation.tar.gz` 的 `tests/unit/test_factor_research.py` 中；本批新增边界测试与本文档。改后 `source-after-gtja-rolling.tar.gz`，摘要见 `gtja-rolling-source.sha256`。

恢复先解包到独立目录逐文件比较，仅逆转本批，保留后续用户改动；不要整目录覆盖或恢复数据库。没有触碰生产数据和配置。
