# 基准指数输入契约 · 第三十二批 A（本地基础，尚未开放页面）

## 本次实际变更

- `factor/benchmark.py`：个股与独立指数按规范化后的同一观测时刻精确对齐。保留个股全部行和原索引，不前向填充、不按最近时间替代、不将缺失转换为零。没有共同时间时明确失败。
- 指数必须有明确的 `kind=index`、市场、代码和 `MAC_INDEX` / `TDX_INDEX` 来源；目前限定上证指数、深证成指、沪深300、创业板指。不按六位代码推测指数身份，尤其不混淆 SH:000001 与 SZ:000001。
- 指数实际／请求复权都必须为 NONE，个股可以保留 NONE/QFQ/HFQ。周期一致、end 时间标记、已收盘布尔标记、开收价格正且有限。无效输入不能变成“指数平盘”。
- `web/factor_benchmark.py`：在进程内复用现有指数服务，不产生辅助 HTTP 用户查询；保留原有 MAC/标准指数接口回退，不调用个股标准行情来代替指数。过滤尾部未收盘行并记录数量，服务失败原样上抛。不购买数据、不新增凭证。
- 因子输入快照保存完整独立指数快照、身份、对齐方式和覆盖统计；恢复时重新核对来源与逐行对齐值。即使重新计算 JSON 摘要，不一致的对齐字段仍被拒绝。拒绝嵌套基准，保持有界输入。
- 原快照类型增补 UTC 和 Asia/Shanghai 时间列／索引，保留时区而不丢失精度；对齐使用上海同一时刻。其他任意扩展 dtype 仍未开放。
- 单股、股票池研究指纹纳入基准契约；后台任务已有完整 attrs 传输，新增测试确认身份变化使缓存指纹变化。无基准旧输入不新增指纹材料，不补入新配置。

这些检查证明输入内部一致，不证明客户端上传行情一定真实，也不构成已取得历史指数成分库。
