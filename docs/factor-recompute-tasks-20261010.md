# 因子存档显式重算后台任务 · 2026-10-10

本批为本地实施和验收；完整统一因子目标尚未完成，不部署生产。

## 已实现

- 新增 `/research/factors/recompute/async`，保留同步重算接口兼容。只接受当前账户有效因子存档；提交要求原档 ID、预期摘要、预期版本，版本变化返回 409，未启动任务。
- 使用 `factor_recompute` 接入已有内存／持久任务。提交时复制完整原档（含全部冻结输入、旧公式、实际参数、旧配置），worker 不再读云档、联网取行情或写回原档。任务内再次核对来源身份、版本及完整 JSON 摘要。
- 支持单股序列及多远期截面存档；沿用既有旧配置迁移规则、实际参数和计算函数。没有修改公式、统计、MyTT 或缠论。原档缺字段、未知配置或当前实现不兼容时明确失败，不用当前默认值替补。
- 复用真实因子／窗口进度、取消、超时、账户隔离、任务资源和 16 MiB 完整结果限制。结果是完整的 `factor-research-v1` 重算封套，不是裸数值结果；超限失败，不截掉来源或结果。任务载荷继续受 64 MiB 上限约束，原云档上限不因此扩大。
- 重算结果保留 `recomputed_from`：原档 ID、摘要、版本、旧公式定义、统计版本和配置迁移。后台结果打开、导出及云保存均保留此封套；不再通过只含数值的快捷存档构造器丢失来源信息。
- 只读预览增加渐进展开的“重算来源”，显示原输入／当前实现边界。重算完成后仍由用户显式保存为独立新 ID，原档不覆盖。
- 输入原档 ID／摘要／版本、账户变化或组件关闭使旧响应失效。保存仍沿用同 ID 重试，不因不确定响应重复创建。
- 自动请求不记入主动查询；只有显式重算提交记一次，取消／轮询／只读打开／保存不追加行情查询。身份来源标记仍不是授权凭证。

## 交互与使用

云存档 → 查看原档 → 按原始输入显式重算 → 勾选确认 → 开始重算。

取得任务编号后，可取消后台任务；“停止等待”仅断开本页等待。关闭原档后，在个人账户 → 后台计算取回完整结果。保存新版本后刷新云目录，原档和新档分别可读。

采用 frontend-skill 的应用页面克制原则：在原折叠区内放状态／操作／结果，不增加卡片；原暗色、字体、按钮、轻分隔保持一致。移除弹窗内指向当前账户页、实际无反应的同页链接，改为明确关闭原档后的路径提示。只读来源默认折叠，完整元数据可展开查询。

## 剩余边界

提交前取数／原档准备仍处于 HTTP 阶段；未取得编号时停止等待后需到后台确认是否已受理。重算 worker 使用提交时的完整原档，即使之后修改备注或移入回收站也不改变已冻结输入；如要停止须取消任务。未自动创建或覆盖任何云存档。

同账户、同源码／数值环境、同冻结原档可复用已有完成任务；结果时间保留该次计算时间。保存为新版本仍生成独立存档 ID。持久服务故障恢复从冻结输入重新计算，不宣称逐因子检查点续算。
