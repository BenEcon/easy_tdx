# 因子截面检验接入共享后台任务 · 2026-10-10

## 本批已实现（本地，非完整目标完成声明）

- 新增 `/research/factors/evaluate/async`，页面改用共享任务提交／轮询／取消。原同步接口仍兼容。
- HTTP 阶段取得完整股票池、已收盘日线及量额资格后冻结；任务执行不再联网补数。冻结保存股票池顺序、参数、所有行情及属性，执行版本包含源码及数值环境。
- 既有内存执行器和独立持久工作进程均支持 `factor_evaluation`。同一纯计算函数生成研究结果、数据来源和完整存档输入，同步／异步一致；没有修改统计、缠论或 MyTT 算法。
- 持久模式复用同账户、同版本、同冻结输入的既有任务，跨账户不共享结果。沿用安装级、账户级并发及存储上限；因子结果在两种执行模式都检查完整 JSON 和 16 MiB 单任务上限，超限明确失败，不能截断。
- 输入／页面／账户切换使旧响应失效。取消通过服务端控制面发起；失败、取消、超时均不显示部分成功结果。“停止等待”只断开页面等待，不宣称停止后台计算。
- 明确区分提交前取数、排队、计算、正在取消、完成、失败、已取消。当前只有真实任务状态与服务端已用时间，不伪造总体进度百分比。
- 仅显式提交计入主动查询；内部取数、轮询、取消不新增查询事件。取消是任务管理操作，仍沿用原有审计。

## 页面取舍与操作

视觉取舍：沿用暗色、轻分隔、原有按钮和留白，不增加卡片或新强调色。内容顺序：配置 → 提交／状态与控制 → 结果／存档。交互以状态更新、取消确认及输入失效为主，无装饰动画。

1. 在量化研究 → 因子检验选择股票池、因子和远期窗口，点击开始。
2. 取得任务编号后，可直接取消后台任务；没有编号时，停止等待后需在个人账户确认是否已提交。
3. 只有任务完整完成才允许显示、保存、导出研究；导出仍保留所有窗口与原始输入。

内存模式重启不保留任务；持久模式必须显式配置且已有独立工作服务。没有自动切换生产配置、启动生产 worker 或部署服务器。
