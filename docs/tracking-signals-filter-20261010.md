# 缠论买卖点概览与追踪筛选 · 2026-10-10

## 实现口径

- 共用多周期概览表新增「买卖点」，覆盖多周期研究、追踪结果、展开明细及历史预览。
- 直接投影分析器现有结构买卖点，保留一、二、三类、方向、价格极值日、确认日、确认收盘时刻、来源及原始证据；不改变严格笔、中枢或信号计算。
- 标准 MACD 波段已确认事件的 M1 单独列出，资格条件与图表一致，不把特殊、非标准或双线背离改成结构一类点。
- 买卖点仅列极值或实际确认日期落在研究窗口的事件；较早极值在窗口内才确认也保留。旧存档未记录此字段时明确标记，不补算、不假设为零。
- 汇总数字可点击筛选：覆盖、全部、笔向上/向下、双线轴上/轴下、已确认背离、结构买/卖点、M1 买入/卖出提示。每个标的每项计一次，不按信号条数累加。
- 点击数字清空旧搜索和状态条件，展示完整匹配集合；可再叠加搜索或状态筛选。再次点击或「清除筛选」取消。
- 筛选后结果表使用所选周期，不再固定显示第一个成功周期。0 项有明确空状态，分页归一；切换批次或分组清除旧筛选。
- 历史分析使用保存的原值筛选，不请求新行情。已确认历史事件不是当前触发信号，也不表示现在适合买卖。
