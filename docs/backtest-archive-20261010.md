# 普通回测完整结果原档（2026-10-10，本地未部署）

## 实现与边界

原“保存策略”保留配置与绩效摘要，不能代替完整回测记录。本轮保持策略库行为，新增独立 `backtest-research-v1` 原档，支持手动账户云保存、JSON 导出／导入、只读重开、回收站和隔离备份恢复。

保存实际提交请求（完整原行情、标的、周期、复权、区间、策略参数、资金及所有交易费用）、原来源元信息、完整服务端结果（净值、成交、持仓、绩效／指标状态、配置、数据依据及未知附加字段）。来源雷达条目与完整输入独立保存，不依赖原任务仍存在，也不混入回测结果。上传内容仍明确为未经服务端认证的用户存档。

同步回测现在记录执行源码／运行库指纹；存档保留该值，不声称能自动运行旧代码。旧结果无执行版本时不补造。回测图表未封存的技术指标与前端评级不补算；重开直接显示行情、成交、净值及原绩效，不发取数、指标或缠论计算请求。完整原始 JSON 始终可查看／导出。后续原算法复现、回测原档显式差异重算仍属总计划剩余范围，不以策略库重跑冒充原版本复现。

实际提交时冻结输入与来源，成功时冻结结果和完成时间；保存、导出不读取后来变化的表单。换行情、换账户、清除或失败均清除旧原档资格，迟到结果不能写入新状态；显示结果与冻结原档分别复制。同步回测增加可选 X-Task-Owner，服务端与真实 Cookie 核对，不允许旧账户请求在另一账户下执行。自动雷达复核仍为 system，不进入主动查询统计。

前后端校验原档版本、参数类型／完整性、行情与复权口径、净值日期有序且来自原行情、成交日期／方向／字段、绩效字段和独立扫描来源。允许原绩效的 null 与其状态说明，不把它转成零；未知合法 JSON 字段原样保留。新 kind 接入现有容量、账户隔离、冲突、删除恢复与成对备份体系，无数据库结构迁移。

界面按 frontend-skill 复用现有紧凑深色工作区、折叠来源与报告分区；Playwright 验证实际操作及手机布局。不调整交易撮合、费用、信号或缠论数值规则。

- 前端 **510＋28** 项通过；生产构建通过，既有大分块警告保留。

- 新增前端实际 Pinia 生命周期／冻结存档测试及后端真实冻结股票／实际引擎存档测试。Ruff、格式、Mypy **303** 源文件及 diff 空白检查通过。
- WebKit 临时数据库／账户，使用冻结真实 300450 行情与实际扫描和回测：**800 根行情、800 条净值、20 笔成交**。云端结果逐字段等于实际 HTTP 结果，独立来源逐字段等于扫描回执；本地导出和再次导入均一致。
- 原任务主动清理后实际返回 404，重开与导入仍成功；只读没有取数、指标、回测或缠论重算请求，pageerror=0。自动复核的回测请求携带预期账户且标记 system。
