# GTJA143 · SELF 递推与数值范围（2026-10-10，本地）

## 来源与明确约定

独立实现 GTJA143，不复制 BenEcon 受限代码。核对原始 2017-06-15 研报第15页公式及第31页 SELF 定义，并对照 DolphinDB 官方 Apache-2.0 固定提交 `43ace2cc4b81d048864ec2e40c25728d5d464e05` 的143接口。原研报不重新分发／改许可；项目现有 NOTICE 和 Apache 许可继续保留。

上涨时 `F[t] = F[t-1] × (C[t]−C[t-1])/C[t-1]`，否则保持前值。乘收益率本身，不是1加收益率，不是可交易净值。SELF 是上一根因子值。原文没有规定种子，本 App 固定初始值1（与参考模块初始尺度一致），首根不发布，连续第二根才输出。无可编辑窗口，不为凑参数引入任意“回看长度”。

缺失、非正、无限价格重置种子；缺日沿用现有时序引擎的实际观测根数口径，不悄悄补日历。结果依赖完整输入起点，截短历史可能改变重叠值，追加未来不改变过去。股票池研究须核对各股历史起点及断档，不能仅凭最少2根认定已收敛或具有可比经济含义。

80位十进制内部状态，价格用浮点往返十进制值比较，避免微小上涨在除法后消减成零。输出超出 float64 范围时留空，但保留内部状态，后续回到范围内可恢复；不钳制、不永久变零、不因显示下溢重新设为1。内部指数范围明确放大以覆盖现有有界请求，不向 API 输出 Decimal／Infinity。

实现版本 `gtja191-complete-window-v12`。通过已有统一注册进入中文目录、公式释义、单股序列、股票池研究、任务、导出和原档；不另设平台，不改缠论。
