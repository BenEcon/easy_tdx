# 雷达复核的独立研究存档 · 2026-10-10

## 本轮交付（本地，未部署）

继续总计划第 8／9 阶段。此前图表存档只保留任务编号和图表当时的行情；原任务清理后，无法独立查阅原策略参数和窗口信号，回放前缀也不包含完整原扫描预热区间。

新增可选 `radarSource`（`radar-archive-v1`）：

- 从已验证的原任务回执复制所选条目、原策略参数、全部窗口信号、完整行情、复权／截止／指纹、任务与读取时执行版本。
- 图表数据仍只保存当前研究图表／回放前缀；原扫描来源独立保存，不拿完整后缀喂给较早截止的图表或显式重算。
- 本地快照、导出／导入、账户云存档和按当前版本另存重算结果均保留来源。打开存档不依赖原任务缓存、不查询行情、不执行原策略。
- 当前标的、行情和来源绑定不一致时拒绝保存；改变输入／账户／路由后清除旧来源，不把旧来源附给新研究。只有用户明确保存才写本地或云端。
- 新 UI 采用 frontend-skill 的紧凑折叠说明、两列元信息和轻量信号列表；手机单列。原扫描与后续研究的区别、上传来源非认证凭据、旧档缺失原扫描内容均有明确文字。
- 原存档 `client_archive_not_server_verified` 属性不变。这里只验证内部一致性，不声称上传者不能伪造、不声称历史当日数据版本，也不声称当前算法结果等于旧算法结果。

## 实现边界

- 沿用存档 schema 1 的可选字段，不新增数据库迁移，不覆盖旧存档。
- 服务器独立校验任务引用、目标市场、参数、来源元信息、有限有序已收盘 OHLCV、原窗口信号及所选信号。源任务已不存在也可以读取或导入；管理员不能绕过他人存档归属。
- 同一根 K 线可能同时有多个策略信号，不能用窗口根数限制信号条数，也不能按日期去重。
- 来源字段只在从雷达原任务成功读取并完成当前结构分析后关联；旧雷达链接／普通研究不补造原扫描来源。Vue 响应式对象采用 JSON 脱离复制，避免 `structuredClone` 对 Proxy 抛错。
- 本轮是缠论图表研究存档链路。普通回测完整结果云存档、五周期研究独立来源的完整贯通、市场／板块全链路和原执行版本复现仍需继续，不以此替代总计划其他范围。
