# 追踪标的：站内后台分析与滚动修复

## 范围

- 将追踪分析的队列、截止时间、周期、分组快照、结果与进度移到应用级状态。离开 `/tracking` 不再中止任务，返回继续查看同一批次；其他页面顶部提供进度和返回入口。
- 本次是同一浏览器标签页内的后台执行，不是服务器持久任务。刷新、关闭标签页、退出登录、权限撤销会中断；浏览器休眠可能暂停。页面明确提示此边界。
- 同时只运行一个批次；运行中不能更换分组或参数，可主动停止。停止保留已完成项，其余标记“已停止”；失败项和板块展开失败仍展示具体原因。
- 不修改缠论规则、行情复权、共同截止时间、板块成员展开、顺序分析及原有查询统计口径。

## 隔离与结果一致性

- 任务冻结启动时分组、周期、清单版本；返回页面不会清除结果，导出使用同一快照。清单版本不同会提示重新分析。
- 应用级独立 watcher 跟随账户与权限；失去权限或切换账户清空私有结果并取消请求。
- 每个异步发布都检查任务代次和账户。已取消旧请求的迟到异常不能终止新任务。
- 行情和分析请求附带 `X-Tracking-Owner`；服务端校验当前登录账户与追踪权限，拒绝跨账户 cookie 和权限已撤销的后续请求。不改变普通研究接口的既有无此头请求行为。

## 页面

- 追踪工作区承担垂直滚动，解决桌面路由容器裁剪造成底部不可达。
- 长名称、提示和进度自动换行；结果表高度随视口限制，表内可横向和纵向滚动；到达表格底部可继续滚动外层到分页栏。
- 保持现有深色界面、紧凑按钮和表格风格。

## 验证

- 前端全套 639 + 28 项通过；最终滚动样式更新后，任务生命周期/账户隔离 17 项再次通过。
- 后端账户、用户活动、请求安全及追踪 owner 回归共 57 项通过。
- TypeScript/Vite 构建通过，Mypy 319 个源文件通过，相关 Python Ruff 检查通过。构建仍有原有图表 chunk 大于 500 kB 提示。
- 实际 WebKit 验收使用临时账户与合成标的、固定行情，并为行情请求增加延迟；不是实盘结论验收。
  - 桌面启动 12 个标的后切到个人账户：观察到 3/12、10/12 持续推进；返回得到 12/12 成功，无结果重置。
  - 桌面 1440×1000：工作区内容高 1969、可视高 906，可滚动至分页栏；整页宽度仍为 1440。
