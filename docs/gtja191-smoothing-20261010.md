## 原公式与明确适配

使用首批记录的原始报告及 DolphinDB Apache-2.0 固定提交 `43ace2cc4b81d048864ec2e40c25728d5d464e05`。本批按 PDF 技能完整目视检查公式页 11—17 与算子页 31，并逐项对照参考函数；原件不纳入发布包。来源摘要与许可文件见 `gtja191-foundation-20261010.md`。不复制 BenEcon 专有代码。

两处差异已进入用户可查询的中文元数据：

- 081 原表为 m=2，参考模块为 1/21；本实现按原表采用 2/w。
- 173 第三项按原表使用 log(C)，参考模块使用 C；本实现保留对数项，不因混合价格／对数单位而自行改写或归一化公式。

原表规定递推关系，但没有完整规定初始种子、缺失与暖机。此处采用明确、可复核的工程适配，不宣称与参考软件逐位相同：

1. `Y = m/w × 当前输入 + (1−m/w) × 前Y`；首个有限输入作为种子，非 adjusted EWM。
2. 每层连续累计 w 个有限输入后才发布；下一层用上一层第一个已发布值作种子，并独立暖机。因此嵌套 SMA 的种子不等于从未暖机的中间状态开始递推。
3. 缺失、非法原始输入或非有限中间值重置相应状态，不跳过缺口继续递推。价格差／价格比会检查完整滞后区间，避免在中间断档上搭桥。
4. 零量可作为有效量输入，但 009／068 的量分母为零时中间结果无效并重置；平坦区间、对数平滑分母为零等不填 0 或伪造值。
5. 最少输入不是收敛保证。递归结果依赖历史起点，截短历史可能改变重叠日期；追加未来数据不能改变过去值。原档保存全部实际输入与版本，页面说明可查询。

原有基础 RSI／MACD 不替换：其初值、暖机及舍入口径不一定相同，不能因为名称相近就当作完全同义公式。新增同家族若实际窗口相同则拒绝重复配置。
