## 一、文档第一张图是否是当前标准？

**是，第一张图与目前标准波段背离的核心判定一致。**文档随后提出的文字方案，则是对它的修改，不是当前已生效的规则。（来源：《2026.10.7-1.docx》第 1 页，用户提供的文档。）

底背离的主要区别如下：

| 条件 | 当前标准版 | 文档拟调整 |
|---|---|---|
| 柱色结构 | 绿 A → 红 B → 绿 C | 不变 |
| A 的范围 | 末尾双线持续位于零轴下的有效部分 | 不变 |
| A、C 零轴条件 | DIF、DEA 整段均小于零 | 不变 |
| B 零轴条件 | DIF、DEA 整段均小于零 | DEA 保持小于零，DIF 允许短暂略高于零 |
| B 价格 | B 最低必须高于 A 最低 | 允许等于或低于 A |
| C 价格 | C 最低 ≤ A 最低 | 不变 |
| 面积 | C 绿柱面积小于有效 A | 不变 |
| 双线极值 | C 段 DIF、DEA 谷值分别高于 A 段谷值 | 不变 |
| 最终确认 | C 柱色结束，完整复核通过 | 建议保持不变 |

还有两个容易忽略的细节：

- A 一旦截取，**价格、面积、DIF 和 DEA 都使用同一个有效 A 区间**，不能分别挑选对自己有利的范围。
- C 尚未结束时，比较的是“截至当时”的累计面积与极值；后续面积扩大、双线继续下探，都可能使候选失效。

这里的“标准”是网页中已约定的工程规则名称，不意味着它是所有 MACD 分析或缠论解释的统一标准。

## 四、是否包含特殊波段背离后来出现 C 的情况？

**能覆盖其中一部分，但不是“出现绿柱就自动升级”。**

这个案例恰好可以说明两者的关系：

1. **9 月 11 日，18.25 出现在红柱 B 中。**  
   当前程序确实生成了特殊波段底背离候选。

2. **9 月 15 日，价格降至 18.01。**  
   9 月 11 日的特殊候选尚未反向成笔确认，就被新低打破，所以失效。现有记录也是这个结果。

3. **9 月 16 日，C 段出现 17.80。**  
   如果采用新价格规则，可以形成另一条独立的 ABC 波段背离记录，随后于 9 月 17 日确认。

建议把它们展示为“相关的两次观察”，而不是把旧特殊候选改名、移动到新日期：

- 特殊记录：B 内先出现价格突破，等待反向成笔。
- 标准记录：C 出现后，重新核验面积、双线极值及其他门槛，等待 C 结束。

## 五、新方案有哪些需要明确的边界？

### 1. 放宽 B 价格是合理的规则扩展，但会改变旧版结果

红柱只说明 DIF 高于 DEA，并不要求价格一定高于前一绿柱段的最低价。MACD 本身由收盘价的指数移动平均计算，指标与价格极值并不是同一种测量。[Fidelity 的 MACD 说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)

所以，允许 B 创新低，在指标逻辑上没有矛盾；但它确实取消了此前明确设定的门槛，需要记录规则版本，不能把新增结果说成旧版原本就应确认。

### 2. “只要求 C ≤ A”不保证 C 是整个 ABC 的最低点

例如：

- A 最低 20；
- B 最低 18；
- C 最低 19。

按文档的新价格条件，C≤A 成立；但真正最低点在 B，不在 C。

因此建议区分：

- **波段背离候选**：按文档，只要求 C≤A，其余指标条件通过。
- **整个 ABC 新低标签**：另检查 C≤min(A、B)。

是否把后者作为 M1 的额外门槛，需要单独决定，不能悄悄加进去。均胜电子的 17.80 同时低于 A 和 B，因此不受这项选择影响。

### 3. “略高于零、短暂跨轴”还不是可执行的完整规则

至少需要明确：

- “略高”用什么尺度：固定 DIF 数值、相对 A 谷值比例，还是价格归一化数值？
- “短暂”限制连续几根，还是累计几根？
- 多次跨零如何处理？
- 恰好等于零是否算跨轴？

我不建议直接写成“DIF＜0.1”这类固定数值：不同股票价格与周期下，含义差别很大。

**本例没有跨轴，所以建议先把 B 价格放宽和 B DIF 跨轴容差分开验证。**
