缠论规则调整与候选确认方案

已读完《2026.10.4-14.docx》，核对了三张配图、当前代码，并重新运行了相关案例的局部成笔检查。文档中的三项可以形成一套一致的方案；第 3 项并非完全重复，它补充的是失效历史的追踪。本轮没有修改程序或部署。

一、非标准波段背离：按文档明确放宽价格关系

这次相较当前程序，有两处实质变化：

条件当前非标准版文档拟采用
底背离 B 与 AB 最低 > A 最低B 最低 ≥ A 最低
顶背离 B 与 AB 最高 < A 最高B 最高 ≤ A 最高
C 与 A 的价格关系C 必须达到或突破 A 极值不限制高低关系

其余条件继续保留：

  • A 使用完整原始同色柱波段。
  • 完整 B、C 的 DIF、DEA 保持在对应零轴一侧。
  • C 同色柱面积严格小于 A。
  • 底背离比较段内 DIF 最低值是否抬高；顶背离比较段内 DIF 最高值是否降低。
  • 不要求 DEA 极值改善，但保留 DEA 零轴检查和 B 段双线回拉检查。
  • C 结束后完整复核，才最终确认。

这里应明确：“不限制 C 的价格”不等于“不比较 A、C 的指标”，也不等于只要面积缩小就成立。

建议仍在提示框区分：

  • 价格达到前极值：C 等于或突破 A 的价格极值。
  • 价格未达到前极值 · 动能减弱：C 没有达到 A 极值，但面积与 DIF 条件成立。

两者都可以使用非标准三角形；实心表示“这套非标准指标规则已经确认”，不能直接解释为底部／顶部已经确定，也不应因此增加 M1。

此次只调整非标准版。标准版的 B 严格价格关系、C 达到前极值、DEA 改善等条件保持不变。

另一个边界是：允许 B 等于 A 后，同一组行情可能先出现特殊波段提示，后来又出现非标准波段提示。二者依据不同，应分别保留，不能互相覆盖。

二、局部反向笔确认：解决“已满足局部条件，却未被全局笔选中”

当前程序的确认，不仅要求存在符合严格条件的反向笔，还要求它被选入全局笔序列。这会让部分候选一直等不到确认。

文档采用的方案是：

从候选极值对应的分型出发，独立验证反向成笔；不再把“被全局笔序列选中”作为指标确认的必要条件。

但这不是放松笔的定义。仍然要求：

  1. 使用截至当时的完整行情进行包含处理，不从信号点截断后重新合并。
  2. 起点、终点分型成立。
  3. 顶分型的高点、低点均严格高于底分型。
  4. 满足当前新笔所需的独立 K 线间隔。
  5. 只使用当时已完成的 K 线。
  6. 确认前如价格或指标条件失效，候选仍须失效。

全局笔、线段、中枢和高层级递归不因此改动。网页最好明确标注 “局部反向笔确认”，并允许查看这条确认用的局部笔，避免用户在主图全局笔中找不到它。

三、第 3 项与前两项是否重复？

空心／实心的部分重复，可以合并成一条统一展示规范；历史追踪部分不重复。

前两项回答的是“什么条件生成、确认信号”；第 3 项还回答“曾经出现的信号后来为什么没了”。

建议统一为：

状态图形样式含义
有效候选、初步确认原类别颜色，空心虚线尚未最终确认
最终确认原类别颜色，实心实线已满足对应确认规则
已失效、被替代灰色空心，降低透明度曾经成立，但最终未确认

“连续两根柱缩短”等初步确认，也继续保持空心。

特别需要区分：已失效不等于仍在等待确认。否则一直保留彩色空心，会让用户以为这些旧信号还有待确认。

因此建议：

  • 默认主图显示有效候选和已确认信号。
  • 增加“显示失效／被替代候选”开关。
  • 历史列表始终可查询，不随主图隐藏而删除。
  • 点击后显示极值时间、首次发现时间、确认或失效时间、原因及替代关系。
  • 只有确实生成了后续候选，才显示“替代候选”；新价格极值本身不一定构成新候选。

例如 399006 的上述案例，应显示：

11:20 出现特殊底背离候选；尚未满足反向成笔；13:25 因价格出现更低值而失效。

不能只让标记消失，也不能把它变成实心。

另外，历史图上可以把实心标记画在原极值位置，但回放到实际确认之前，必须仍为空心；首次发现之前则不能提前显示，避免产生“当时已经知道”的错觉。

四、建议实施顺序

  1. 保存恢复点、冻结案例，记录当前规则版本与结果。
  2. 修改非标准价格条件：B 允许相等，取消 C 价格门槛，补充价格关系子标签。
  3. 实现独立局部反向笔确认，保留严格成笔条件及两类独立识别依据。
  4. 统一状态展示和历史追踪，补充失效原因、确认用笔与时间回放。
  5. 逐根回放及回归验收：检查顶底对称、等高等低、跨轴、面积扩大、DIF 失效、间距不足，并确认标准版、全局结构和 M1 来源没有被意外改变。

这套方案与文档的选择一致，也保留了必要边界：放宽的是非标准价格关系和指标确认对全局笔选择的依赖，不是放宽面积、DIF、零轴或严格成笔条件。
