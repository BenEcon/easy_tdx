# 绩效采样口径（本地实现，尚未发布）

契约：`performance-sampling-v5`，指标状态契约：`performance-metrics-v1`，组合估值可用时间契约：`closed-valuation-v2`，交易日历：`sse-cash-2020-2026-v2`。交易、信号、持仓与个体原始净值仍按完整 K 线时间执行；绩效采样不改变缠论规则或交易成本。组合曲线按估值实际可用时点对齐，不再将周一标签的周收盘净值提前放入周一。

## 采样及年化

| 输入 | 绩效收益采样 | 每年期数 |
| --- | --- | --- |
| 1/5/15/30/60/120 分钟 | 交易所本地 15:00 的已观测收盘净值 | 252 |
| 日 | 日净值 | 252 |
| 周／月／季／年 | 对应周期净值 | 52／12／4／1 |

年化收益为 `exp(log(最后样本净值/首个样本净值) × 每年期数/收益样本数) - 1`；这是观察期按频率外推的复利估计，**不是实际日历跨度 CAGR**。无风险利率沿用默认 3% 并除以同一采样频率；夏普、索提诺、波动率使用该频率平方根。此次不更换索提诺原有分母定义。

频率约定参考 [Empyrical 官方 API](https://quantopian.github.io/empyrical/appendix.html) 对日 252、周 52、月 12 的定义；没有引入该依赖。分钟先转日收盘采样是本项目的可比较性选择，不宣称所有平台必须采用此法。

- 总收益及最大回撤保留完整净值范围，包含日内变化。
- 分钟年化仅覆盖首个收盘至末个收盘；其前后部分仍计入总收益，页面明确说明。
- 不足一年显示外推风险提醒，不宣称实际取得全年收益；本报告不是 GIPS 合规业绩展示。
- 时间缺失／重复／乱序、同日多根伪装日线、周期重复／缺口、净值非正、有效收盘收益少于两项：相应年化与风险值不可用，不以 0 代替；JSON 输出 null。
- 中国现金股票交易日历当前覆盖 2020–2026；包含 2020 年春节延长休市修订，调休补班周末不作为交易日。显式日线／分钟输入超出覆盖范围时不虚构完整日历，暂不输出依赖日收益连续性的年化值。其他年份日历仍需补全；不适用于港股通、期货夜盘或其他交易市场。
- 周／月／季／年检测周期序号是否连续，不用 252 代替它们；Web 在取数入口过滤未收盘柱。
- 只有日历完整核验为“整个周期没有交易日”的内部空缺，才沿用前次估值作为独立绩效样本，保留周期长度；不把跨两周的收益当一周。休市样本记录周期、采样时刻、前次观测、值与原因，绝不添加 OHLC、交易或原始净值行。
- 休市估值采用该日历周期末日 15:00 作为绩效记账时点，不表示那天存在市场收盘。只在已有观测范围内生成，不外推快照末尾；已知有交易日的空缺、未知年份和非正／非有限前值不能因此变为可用数据。
- `sample_count` 包含明确标识的休市估值，`observed_sample_count` 只计真实观测。至少需要 3 个有效收盘观测；休市沿用不制造独立样本、不能满足原本不足的统计门槛。
- 直接 Python 旧调用未声明周期时保留日线默认并记录 `legacy_daily_default`；同日多根时间自动识别为日内，但不根据数据缺口猜测周月周期。建议显式传 `BacktestEngine(category=...)`。
- 结果固定保存输入周期、采样周期、频率、样本数、范围、警告和不可用原因；不随网页表单后续变动。

## 组合

各成员仍独立分配资金。显式周期组合净值按收盘估值可用时间的并集对齐；成员开始前保留分配现金，开始后延续最后观测估值；不将缺失时间标成真实行情。回撤统一为峰值减当前净值，除以当时峰值。纯旧版未声明周期调用仍保留原时间标签，不能视为经过新日历验证。

同周期组合与单股共用绩效模块，不再把总收益直接填作年化收益。混合周期新增独立共同估值采样，完整估值并集仍用于总收益与回撤：

- 选择日／周／月／季／年中最粗周期；分钟之间或分钟与日线共同取 15:00 收盘。不同分钟起点标签先换算收盘时间，已提供的 `period_end` 必须与声明周期一致。
- 周、月等采用已核验日历的最后交易日；整周期无交易日不虚构行情；未知日历年份明确拒绝构造未经核验的组合估值时点。时区统一到上海本地时间用于合并，原始交易及个体净值标签不改。
- 每个共同采样点只允许引用该成员当时最新应完成的原生周期。例如 2026-03-31 月末，周线成员使用已完成的 03-27 周线，不得用尚未完成的 04-03 周线；这一估值明确标注为沿用值，不是 03-31 的真实股价。
- 开始于所有成员已有观测之后；超出任一成员已观测原生周期的尾部时点不外推年化，并记录排除成员及原因。完整组合曲线仍保留尾部沿用估值。
- 内部缺少应有原生收盘值或成员净值非正／非有限，保留对应时点和失败原因，整段年化不可用；不删掉缺口、用更早净值补齐或压缩收益间隔。未收盘观测不进入组合估值。
- 逐时点返回成员类别、应有收盘、实际估值时刻、原标签、估值年龄及失败原因。网页在现有“本次计算数据”里按需展开、逐时点查看，不一次渲染整个审核表。

完整休市周现在采用上述独立绩效采样，组合仍逐成员检查其最近应完成的原生周期；共同估值依据明确显示“整周期休市 · 估值沿用”。这一约定适用于当前没有 K 线之外资金注入、融资计息和独立公司行动现金事件的回测模型，不声称是休市期间实时报价；今后加入这些现金事件必须重新核验沿用假设。未知年份日历、真实冻结行情跨入口验证仍未完成。

平均持仓时间保留日历天的小数；跨成员不相互配对 FIFO。峰值至最大谷底的距离仍以 K 线根数计，页面不再标为天，也不冒充恢复到前高所需时间。

## 网页和恢复

单股、组合、多策略、单策略寻优和全策略寻优携带同一采样契约。寻优展示的是输入共同采样范围，不是每个候选都通过净值有效性校验的证明。按有限总收益降序排名；无效总收益行保留在末尾供查看，不参与最优选择，全部无效时 best 为 null；热力图无效单元格为 null。

组合评级只读取已记录的后端绩效，不再按 252 对旧图表曲线隐式重算。必要指标不可用显示“暂不评级”。历史结果保留原值并展示历史口径；新旧版本不混作同口径评级。

寻优检查点增加 `performance_contract`；旧口径结果拒绝静默恢复。工作任务另受完整执行版本约束。撮合、信号、成本、权益检查点不因绩效采样变更而改写内容。

## 指标状态与交易统计

Python 数值字典保留 NaN／inf，HTTP 和 `BacktestResult.to_json()` 严格 JSON 使用 null，`performance_basis.metric_status` 同时记录 `finite`、`unavailable`、`positive_infinity`、`negative_infinity` 及中文原因。寻优每个网格点和全策略排名亦携带该状态，检查点恢复核验状态与数值一致。

- 真实零收益、零回撤、零波动仍为 0。夏普分母标准差为零时不可估计，显示“—”，不填零。
- 卡玛在正年化收益且零回撤时为正无穷；零收益／零回撤不可定义。取消 1e-10 回撤阈值，不把真实微小回撤自动视为零。
- 索提诺仍采用原“负超额收益子集的总体标准差”分母，未替换为另一套 downside deviation 公式。无负超额收益且平均超额收益为正时记正无穷；只有一个负收益或负收益完全相同时分母为零，不可估计。该口径限制在结果中显式记录。
- 利润因子为已实现总盈利／总亏损绝对值；有盈利无亏损为正无穷，仅亏损为真实 0，没有盈亏或仅持平为不可计算。新结果不使用 999 哨兵值；实际计算得到的有限 999 仍保留。
- 仅非拒单的 SELL 记录计入成交统计。盈利 > 0、亏损 < 0、持平 = 0 分开计数；胜率 = 盈利次数／已成交 SELL 总数（含持平），没有样本为不可计算。拒单数仍独立保留。
- 缺少成本基数、非有限盈亏或部分盈利／亏损记录无法计算收益率时，不静默删除记录后计算该组均值／极值。成交数量仍保留。
- 空／单点净值不能定义区间收益，但已知成交及起止资金不再被整份清零。初始净值非正不能定义总收益；中途归零仍保留可计算的总收益与回撤，年化按采样契约拒绝。
- 持仓天数按每个成员独立 FIFO 队列计算，缺时间／数量、配对不全为不可用，不再假设每笔 100 股。真实同日配对可为 0 天；分钟持仓保留小数日。原始成交、成本和曲线不因统计变化而修改。

网页复用指标表和可展开说明，显示 ∞／—／真实零值。非有限且参与评级的必要指标使其“暂不评级”，不会以 999 取得高分。保存策略快照附带指标依据，比较页保留依据；旧历史不覆盖、不根据数值恰好等于 0 或 999 猜测状态，明确显示历史口径，重新计算才能取得新版状态。历史评级保护与版本展示详见下节。

## 结果版本与历史评级

网页结果级评级使用 `performance-grading-v1`，支持已记录的 `performance-sampling-v5` 和 `performance-metrics-v1`。单股、组合和寻优入口先核对采样周期／期数／数量与每项评级指标的状态。有限状态与非有限数值矛盾、状态缺失或必要指标不可用均不输出可操作评级；低交易样本正常降权的真实不可用逐笔指标仍允许按原净值评分规则计算。不修改评分阈值或有限值公式。

- 无依据以及采样 v1–v4 为历史口径；未知未来版本为未支持口径，字段不足为依据不完整。均保留数值，不显示新生成的评级、得分条或否决建议。
- 旧日线浏览器重算函数只保留为冻结兼容回归工具，生产页面不调用。旧值 0／999 不被猜测成缺失或无穷；有明确状态的新结果仍按该状态显示。
- 寻优输入范围不等于候选有效性证据：共同采样版本和每个候选自己的指标状态分别核验。不会用最优行的状态替其他行评级。
- 对比表并列显示原值和口径；版本、周期、采样范围、年化方法、无风险利率及估值口径不同会明确提醒，不做跨口径排名。
- 新策略快照保留完整绩效、计算依据、快照版本及适用的评级版本；旧记录不批量迁移或补造元信息。保存历史结果也不声明为新版评级。Vue 响应式数据复制为独立 JSON 形状，精度不舍入，有限 0／999、null 与非有限指标状态保持。
- 这些快照不是完整行情、成交和图层的精确研究回放；后续账户云保存仍需独立完成。使用当前行情重新运行会生成新结果，不能冒充对旧结果原输入的复算。

- `--output csv` 现在输出真正的指标 CSV（不是伪装 CSV 的 JSON）：`scope,metric,value,state,reason`；组合同时列汇总和各成员。它是绩效表，不含完整交易明细或净值，完整结果请用 JSON。非有限值留空，状态和原因保留。
- 人类表格显示 `—`／`∞`／`−∞`，真实零与有限 999 原值保留；打印采样周期、收益样本、契约、警告及不可用原因。
- `run-all` 总收益非有限行不能成为最佳策略；综合评分保留原有限值公式与权重，必要指标不可用、零回撤使收益／回撤比不可有限计算时暂不评分，不再填 999 获得高分。多因子排名和最佳图表选择同样不以无效总收益当最佳。
