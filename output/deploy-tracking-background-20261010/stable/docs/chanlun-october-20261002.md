## 已确认并实现的判定修改

现有双线背离仅要求极值次日价格反向就确认；现有波段背离必须柱缩短或变色才产生候选。前者确认太早、后者提示太晚，是文档案例所描述问题的直接原因。

用户本轮已明确：

1. 连续两根同色柱缩短或有利变色记录初步条件，后续仍可能失效；价格极值日与真实可用确认日必须分开，不能利用后续数据提前确认。
2. 波段最终确认等待 C 段柱色反转结束，按完整 C 的面积、双线极值、严格新高低点和 ABC 全段同侧条件复核。
3. 双线最终确认等待从信号极值起的已确认反向笔。使用现有严格笔规则及 `confirmed_index`，暂定尾笔不计；每个前缀独立生成笔，确认时间是证据首次可知的当前 K 线。
4. M1 单列为 MACD 波段确认提示，不混同严格中枢结构一买／一卖。只展示最终确认波段；底部红色买入提示、顶部绿色卖出提示；不会写入结构 `mmds` 或策略。双线统一圆形。
5. 全段零轴同侧新增 B 段检查；触及零轴也排除。高层级结构独立校验保持不变。

波段在首次满足条件时即出现候选，包括只有一根柱的 C，不再要求先缩短才提示。已有的最近局部极值比较门槛保持不变；但只依赖该时刻的双线候选证据，不必等双线最终成笔，以免把两个不同确认规则绑定。

所有候选保留初步条件满足时间、失效／替代时间及原因。双线候选等待反向笔期间，若价格再创新极值，或任一 MACD 线不再严格优于原对照，记为失效／替代。初步确认仍为空心，不生成 M1。最终确认的已完成历史事件不因后来另一段走势而回写；新走势生成新的事件。

回放前缀独立计算，不以最终窗口的笔倒填过去信号。双线的极值日、初步条件日和最终确认日有独立合成样例覆盖；顶底镜像测试、ABC 触轴/跨轴、单根 C、柱面积后续扩大及初步条件之后失效均已覆盖。
