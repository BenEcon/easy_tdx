## 已实现

1. 双图按交易所本地时间区间联动；周/月 K 按日历覆盖区间显示，不编造子周期行情。缺失对应行情时明确提示。
   - 时间联动默认开，范围联动默认关；主周期与对照周期可独立缩放。
   - 上下、左右布局；窄屏自动上下排列；支持整个对比工作区全屏及降级全屏。
   - 仅沿用共同截止之前已收盘数据计算，保留原有未来数据过滤。
2. 独立“周期明细审核”：主/对照周期切换，查看笔、线段、盘整、中枢、背离与买卖点。
   - 类型、方向、状态、日期、图中可见区间筛选；30 条渐进展示。
   - 失败条件按核验组统计并可进入具体记录；不当作强弱评分，不宣称覆盖未计算的候选。
3. 密集标记用渲染后的中心与尺寸进行最近点命中；真正同位置对象统一选择，不再按信号类型优先抢占。
   - 缩放/改变数据/尺寸变化后重建命中缓存；保留失效历史命中。
4. 详情面板增加图中定位、审核明细与原始记录。定位保持缩放尺度，必要时平移到目标。
   - 手机可选择底部面板；保留悬停预览、点击/右键固定、Esc/外部关闭以及蜡烛日期卡激活规则。
5. 账户偏好保存均线、技术指标、线宽、蜡烛透明度、对照周期、布局与联动设置。提供确认恢复默认及保存失败重试。
   - 修复偏好队列一次失败后后续无法保存的问题；跨账户队列和响应隔离。
   - 研究快照保存原始行情、分析结果、复权/采集元数据、接口返回的规则版本、显示设置与备注。
   - 快照按账户存入当前浏览器 IndexedDB，独立查看、不重算结构、不覆盖当前研究；支持导出/校验导入 JSON 和二次确认删除。导入有 25MB、行情条数、格式及 OHLC 基础检查，并明确内容未经服务器重新核验。
   - 明示本地存储、不跨设备同步、并非加密存储；清除浏览器数据可能丢失快照。
   - 明示保存的是采集时版本，不冒充历史时点实际可得的数据；没有统一规则版本时明确说明。
6. 性能与稳定性：同快照重绘保留 ECharts 实例/缩放，合并一帧内展示重绘；不再深度遍历完整递归结果监听样式。
   - 对比结构回放有界缓存与同键请求去重；缓存包含标的、周期、完整行情、复权、截止、规则信息与界面版本。
   - 同一不可变行情数组的指标请求用 WeakMap 缓存/去重，旧行情可被回收。
   - 主周期、行业、回放和对照选择变化时 AbortController 中止旧 HTTP 请求，并保留 generation 防止旧结果覆盖。
   - 快照列表只持有摘要，具体结果查看/导出时才读取，避免所有快照长期占用内存。

## 明确边界

- 页面下方原有全域递归等区块仍对应左侧主周期，已在界面说明。独立的周期明细审核提供对照周期的基础结构、信号与诊断，不替换主研究上下文。
- 后端 `chanlun_replay.py` 是同步计算入口，没有任务句柄或协作取消点。取消 HTTP 不保证已经开始的后端计算立即停止；本轮不改算法执行流程，未宣称实现后端任务取消。
- 回放缓存为组件生命周期内有界缓存，不跨用户/会话持久化；快照展示不调用缠论重算，但技术指标可按保存的参数计算。
- 大型 ECharts 打包体积提示仍存在，本轮不更换图表引擎。
