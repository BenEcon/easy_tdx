# 缠论指数与板块入口

2026-10-05：按用户要求暂停《2026.10.4.docx》，将文档衍生观察扩展从发布范围移出，其余功能部署至服务器。发布及最终验收见 `deployment-instruments-20261005.md`；下方初次验收为上一轮历史记录。

## 功能

- 缠论左侧增加个股／指数／板块选择。个股仍使用原有账号股票历史和全局复权设置。
- 指数：上证指数、深证成指、深证综指、创业板指、沪深300、上证50、中证500、中证1000、科创50。
- 板块：一级行业、二级行业、概念、风格、地区；实时目录，可按代码或名称筛选。
- 所有标的复用既有严格成笔、结构、背离与失败原因、失效历史、均线及指标、全屏、逐根回放和多周期研究。未修改这些算法的门槛。
- 切换标的使旧分析和回放失效；请求版本防止较早响应覆盖当前标的。指数、板块不写入个股历史。
- 保留前一轮交互修改：信息卡默认隐藏，点击显示、图外点击隐藏；中枢／线段默认关闭，失效历史默认开启。

## 数据边界

新增 `GET /api/v1/bars/research`，不改变原 `/bars/index` 返回契约。

- 指数优先使用 MAC K线通道（显式 SH/SZ＋NONE），MAC缺失或空行情时用专用 `get_index_bars`；避免 SH000001 上证指数与 SZ000001 平安银行混淆。该调整来自部署后的真实行情验收。
- 板块查询先在所选官方分类目录中查找，再使用目录 market 调用 MAC K 线。不以股票代码前缀推断市场。
- 指数和板块均为 NONE 不复权；不改变用户保存的个股 QFQ/HFQ 设置。
- 快照包含源、实际复权、收盘状态及 instrument 身份。多周期请求、回放代码及导出快照保留类型和市场。
- 不支持的指数 120 分钟明确返回 422，不以 60 分钟替代。板块 120 分钟沿用现有 MAC 5 分钟单位 ×24 实现。
- 无数据、目录无匹配、板块服务离线均明确报错，不回退到个股行情。
- 板块目录本轮最多 5000 项；指数入口为列出的常用沪深指数，不宣称支持全部交易所指数。
- 该功能不等于指数或板块可直接交易，也不证明某种策略适用于所有标的。
