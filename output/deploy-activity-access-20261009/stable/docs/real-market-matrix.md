# 真实行情矩阵与逐根验收

## 冻结来源

清单：`tests/fixtures/market_matrix/manifest.json`。目前 22 份真实 MAC 行情文件，
包含原有 10 份案例及 2026-10-09 本次补采的 12 份。

新增矩阵为以下标的与周期的笛卡尔积，不复制股票价格来代替指数或板块：

| 标的 | 日线 | 周线 | 月线 | 30 分钟 |
| --- | ---: | ---: | ---: | ---: |
| 300750 宁德时代，前复权 | 240 | 150 | 48 | 240 |
| SH 000001 上证指数，不复权 | 240 | 150 | 48 | 240 |
| 881218 汽车零部件，不复权 | 240 | 150 | 48 | 240 |

行业市场值 1 来自 HY 目录，并通过 600699 均胜电子的所属行业响应交叉核验；
目录行、归属行、节点、取得时间、请求及实际复权、原始价格精度保存在源文件中。
源文件和原始 bars 各有 SHA-256。取得器使用隔离临时配置，不更新开发者真实配置。
已存在文件拒绝覆盖；测试本身不访问网络。

这是取得时的历史数据快照，`historical_data_vintage=false`。
不能证明历史各日当时可得的前复权值、成分股归属或行情修订版本。
成交量复权口径未独立核验；原始 float_shares 不是本次质量验收范围，不能据此作财务结论。

## 旧案例保留与时间修正

测试副本只删除衍生 period_end，再按当前 native/end 契约重建，不改价格、成交量或原始时间。
原始闭市标记仍保留，不能将 false 变为 true。

旧 399006 QFQ 案例仅保留作规则回归，不冒充当前指数 NONE 入口验收。
新增上证指数的 NONE 四周期样本独立覆盖当前研究入口。

三个当前月线样本的末根是 2026-10-09 的进行中月线；按取得时刻核验为未收盘，
其余 47 根已收盘。保留图表显示，不能用未收盘柱作最终确认依据。

## 入口与因果验证

`tests/unit/test_real_market_matrix.py` 仅替换网络响应：

- 实际股票图表、内部共用行情加载和缠论计算对照，核验价格、收盘标记和指纹；
- 实际指数／行业研究入口核验身份、不复权、原生标签及价格；
- 实际行业缠论计算和前缀回放的 MACD、笔、线段、中枢、背离、买卖点对照；
- 固定取得时刻，不因测试运行月份改变旧快照的月线确认状态；
- 修改未来价格、成交量和收盘状态不得改变已截断前缀；确认、检测和失效索引不能越过可见位置。

2026-10-09 本轮与既有真实行情／结构因果／行业／对照回放组合回归：
`real-matrix-regression-final.log`，96 项通过，1 条既有 Starlette 弃用警告，146.78 秒。
该结果不代替全库最终回归、浏览器或生产验收。

### 全部内置默认策略与消费入口

`tests/unit/test_real_market_consumers.py` 进一步覆盖清单内全部 **13 份股票样本 ×
20 个内置策略**，不将指数／板块冒充可交易股票。包括原有日线、15／30／60 分钟
以及新增周／月线；四周期新样本只是最初的小范围验证，不是最后的覆盖边界。

- 五入口：单股、单成员组合、多策略单槽位、单策略寻优及受控全策略寻优。
  全部默认参数相同，比较完整绩效、已成交记录、净值和寻优所支持的指标状态。
  组合额外的 total_stocks／total_cash 独立核验，不删除单股绩效字段。
- 单策略寻优公开接口最多两维，其他参数沿用同一注册默认值；全策略受控预设
  是完整默认参数的单点网格。不是全部参数组合或自定义策略的验证。
- 雷达查询去重、收盘过滤、价格及原始信号与真实回测信号发生器一致。
  原始策略信号不等于下一根实际成交，未将两者混为同一日期。
- 修改未来 OHLC／成交数据不影响已观察区间的原始策略信号和全部可计算因子值。
  数值精度比较保留严格因子断言；绩效和净值仅容许 1e-12 相对／1e-10 绝对浮点误差。
- 所有注册因子按实际 Web 路由与 FactorEngine 对照，包含明确不可用的财务因子。
  47 根闭市月线不补造预热行情；请求最小数量并不代表上游一定返回足量样本。
- 真实 300750 与 600699 日线风险对照只使用共同观测收益；两边同时去掉 09-21
  后排除跨缺口的 09-22 收益，不补零、不把跨日收益当作单日收益。

最终 `real-consumers-expanded-first.log`：**808 通过、28 条指标预热／零分母警告，
201.02 秒**。这是最后扩大到全部股票后的结果；此前 163／250 通过属于较小范围。
首次 80 失败／83 通过因测试未按两维公开网格及组合附加字段契约对照，
修正后仍逐项保留指标、状态、成交、净值、来源和输入不变断言，未修改计算源码。

### 已发现、尚未修复的失败可见性问题

`chanlun-factor-silent-error-reproduction.log` 使用有效 240 根真实行情，故障注入让
实际 ChanlunAnalyser 抛异常：`chanlun_bi_dir` 与 `chanlun_mmd` 仍返回整列 0。
因此不能用正常行情的 808 项通过宣称所有异常都正确展示。
解除当前长时任务的源码冻结后，必须移除吞异常转零的逻辑，让 Web errors／CLI
显式报告计算失败；确实无已确认笔／买卖点时的合法零值仍保留，不能更改成笔／买卖点规则。
新增回归必须同时覆盖正常无信号、异常不可用及逐根因果，而不是只检验报错文本。

## 完整逐根验收任务

```sh
.venv/bin/python scripts/verify_real_market_matrix.py \
  --output output/platform-optimization-20261009/real-prefix-matrix.json
```

22 份样本合计 **10034 个前缀**。每个前缀调用真实计算器及完整归属历史输出两次：
一份直接截断，一份保留全长但大幅修改未来价格、成交量和收盘标记。
除传输层 total_count 外，全部结构、历史、条件依据、事件与时点必须相同。
每个前缀保存完整结果的指纹及结构数量，便于相同来源下定位后续版本差异。

报告 running／failed／passed 分开。只有全部案例、全部前缀通过且源码／运行环境未变才写 passed。
续跑需显式 `--resume`，并匹配执行源码、数值运行环境、清单、验收脚本和加载器指纹；失败报告不静默续跑。
运行时必须冻结这些输入与计算源码，不能把旧报告用于修改后的源码。
任务尚在运行时，只能引用已经完成的案例，不能称整个矩阵通过。

CI 新增单独 Ubuntu／Python 3.12 完整前缀门禁，不在六组合平台矩阵里重复运行。
发布工作流通过同提交的 reusable CI 继承门禁，失败／取消不得绕过；always()
只用于保存完整或部分证据，不能把报告 running 当作通过。本地已解析工作流并
校验依赖／权限，未推送、触发远程 CI 或发布，不能宣称 GitHub Linux 门禁已通过。
