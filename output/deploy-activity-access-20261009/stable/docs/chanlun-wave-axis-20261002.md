# MACD 波段解耦与轴侧重新起算（2026-10-02，后续修订）

本次修改已部署至 `https://tdx.bowenv.com/chanlun`，发布记录见 `deployment-wave-axis-20261002.md`。本规则取代同日早先版本中“完整原色柱段跨轴即整体排除”和“波段必须同时满足最近局部极值双线背离”两项要求。

## 用户确认与边界

1. 波段背离独立比较 A、C，双线背离仍比较最近局部极值；不共享这道前置条件。
2. 对完整观察到的 A 色柱段，底背离取 DIF、DEA 最后一次触轴或处于零轴上方之后、两线同时严格在零轴下方的连续尾段；顶背离完全镜像。
3. A 的价格极值、柱面积、DIF/DEA 极值全部在同一有效尾段重新计算。不得保留原 A 的大面积而只截取价格或零轴条件。
4. 从有效 A 起点一直到 C 结束仍检查完整区间。B、C 触轴或跨轴不能通过截取隐藏；不跨越中间色柱段选取更有利的 A。
5. 原始 A 起点被行情窗口截断时仍保守排除；无效或缺失指标值不能被当作跨轴前缀裁掉。
6. 波段仍等 C 柱色反转、完整复核后确认；连续两根缩短只记初步条件。双线仍等严格反向笔确认。M1 仍是 MACD 提示，不进入结构性买卖点及策略。

## 原因追踪与页面

- 新增 `wave_diagnostics`，每个已观察到的色柱波段记录最后一次核验、原 A/有效 A/B/C 边界、各门槛的通过情况和数值、首次候选时间。
- 不生成候选也保留记录，包括色柱历史不足、缺失值、没有有效 A 尾段、价格未突破、面积未缩小、零轴检查失败、双线极值或回拉不满足。
- 拦截历史按连续且失败门槛相同的日期段压缩，保存起止时间和门槛；最新核验保留数值。不是保存每一天的全部数值副本，逐日数值应通过原始快照回放复算。
- “背离／背驰”列表顶部增加默认收起的“波段核验”入口。区分从未有候选与曾有候选后失效。展开显示中文原因、范围及两位小数数值。
- 已生成波段的判定依据显示原色柱段及重新起算边界，明确其不依赖局部双线背离。
- 前端技能影响：沿用深色界面、细分隔线、分层展开，避免新增大卡片；手机窄屏自然换行。
