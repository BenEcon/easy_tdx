# 三层研究工作区（本地验收）

## 布局与交互

- 看图：主周期行情、周期对比、回放及行业对照；默认不启动多周期观察请求。
- 研究：多周期观察、三笔盘整研究、研究偏好与原始快照保存。首次进入才挂载；切走取消未完成请求，已完成结果保留。真正改变行情或参数才清除旧结果。
- 审核：对照周期独立证据与结构明细、主周期完整结构/信号/背离审核。标题明确周期归属，不把另一周期的事件装入主周期审核。
- 桌面保留双图布局；手机一次显示一个周期，通过按钮切换，保存双图快照仍包含两份数据。三层入口支持方向键、Home/End、清晰焦点与减少动态效果偏好。
- 图表日期或对象证据自动进入审核；返回、比较区间定位及确认回放自动进入看图。主周期审核定位显式恢复主图，避免聚焦隐藏的主图却留下对照图。
- 切换层级关闭临时对象浮层、行情提示及全屏，不清除已有快照或证据筛选。手机继续复用原底部详情面板，未另建一套重复证据。
- 使用 frontend-skill 的应用布局原则：图表居主位、单一强调色、标题与留白建立层次，不增加卡片墙。不改变严格成笔、背离、M1 或递归规则。
