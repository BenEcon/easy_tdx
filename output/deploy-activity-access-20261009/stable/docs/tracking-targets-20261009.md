# 追踪标的模块（本地版本）

## 使用方式与口径

左侧导航 → 追踪标的 → 新建分组 → 添加标的 → 选择周期 → 分析本组。

- 个股、板块、沪深指数、场内 ETF/LOF；场外基金明确标注暂不支持。分组可新建、重命名、删除，标的可添加、移除，可加入多个组。
- 板块自身及全部成员股纳入分析。使用成员接口 `count=100000` 的分页获取模式，不沿用板块页面前 200 条展示上限。空响应、数量不一致、达到上限、错误成员均报错，不称全覆盖。
- 按类型、市场、代码去重（板块含分类），保留直接加入和所有板块来源。指数与同代码个股不混同。
- 展开的是查询时的当前成员，并非历史成分；各标的采用同一北京时间截止，每周期最多 800 根，复用原 observations 接口，最近 20 根研究窗口；不修改严格笔、MACD、背离规则。
- 个股前复权，指数/板块/场内基金不复权。核验实际复权和周期。周、日、60/30/15/5 分钟可多选。
- 结果包含均线/价格、成交量、MACD、严格笔与方向、背离和其他观察。分组整体概览汇总已覆盖样本的严格笔方向、MACD 零轴位置及存在已确认背离的标的数，不是组合加权收益或交易建议。
- 顺序计算，显示进度，保留成功周期和逐项失败原因；支持停止和结果 JSON 导出。每页展示 50 个，但计算和导出不截断成员。手机宽表只在容器内滚动。
- 图表入口保留标的类型、市场、周期和复权；页面明确重新查询不等于原批次快照回放。

## 保存与限制

- 清单保存到当前账户的 `tracking_groups` 偏好，不使用全局浏览器清单。最多 50 组、清单 UTF-8 JSON 40KB，整体偏好写入前校验 60KB，为后台既有 64KB 限制留余量；超限明确报错，不截断。成员和分析结果不占偏好存储。
- 保存前刷新账户并校验清单 revision，拦截已发生的其他页面编辑及登录账户变更。**既有偏好 API 无服务端原子 CAS，不保证多设备同时写入强一致**；避免同时编辑同一清单。专用实体存储与 CAS 留作后续，不冒充已完成。
- 不是后台常驻追踪服务，执行时保留页面。停止后不再发起后续分析，已开始的后台同步计算不保证立即终止。组、设置、账户变化清除旧结果并拒绝迟到响应。
- 导出含来源、查询截止、规则版本、研究结果，但不含完整原始行情，不称精确可复现档案。持久批次、历史成分、原始行情档案、持仓风险、授权定时更新为后续扩展。
- 未部署，未修改 Python 计算源、生产用户数据或真实行情冻结清单；原长时验证继续运行。
