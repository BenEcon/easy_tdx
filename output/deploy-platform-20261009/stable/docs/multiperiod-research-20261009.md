## 实施边界

严格笔、背离识别及 M1 不改。新增纯观察层，不生成交易信号，不按周期投票，不以过轴先后顺序拦截结构。
研究窗口放在多周期研究顶部，支持最近 N 根与指定起止时间；每周期显示实际覆盖范围。指标使用窗口前历史预热，窗口只限制统计与事件。
自定义区间终点不得超过主图快照截止。未收盘、跨截止点行情排除，分钟起止标签随数据元信息传递。
MA 研究使用左侧全部实际参数，独立于绘图显隐。MA5/10 与 MAVOL5/10 作为固定快慢观察组另列。

## 设计

视觉：沿用深色低对比背景、清晰字号和细分隔，不新增彩色卡片阵列。
内容：研究窗口与周期选择 → 总览 → 每周期过程与依据 → 跨周期时间对照。
交互：周期摘要展开详情、事件历史折叠、琥珀虚线开关；尊重减少动态效果设置。

## 验收计划

1. 均线连续排列、相等、缺样本、自定义周期、显隐独立。
2. 区间统计/结构分歧、尾段反向、预热和无可用区间。
3. 先后修复、反向失效、零轴事件、未来数据不影响前缀。
4. 严格笔与观察隔离、极值日与可知时间分离、撤销、顶底对称。
5. 小周期范围覆盖与共同截止核验，缺失不推断。
6. 后端回归、前端构建、桌面和窄屏验收、部署备份与健康检查。
