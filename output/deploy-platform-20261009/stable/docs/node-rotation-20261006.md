# MAC 行情全节点轮换 · 2026-10-06

## 故障与边界

601208 日线前复权请求出现 `symbol_bar header` 24 字节残缺响应；300750、300450 及多个页面同样受影响。诊断时应用连接 121.36.248.138，新连接测试超时；123.60.47.136、121.37.207.165 均正常返回三只股票的 600 根日线。上线前原节点已恢复正常，说明问题具有间歇性。

本次针对共享 MAC 行情客户端（同步与异步），遍历全部已配置、兼容该协议的节点，不把标准 TDX 节点混入 MAC 池。未修改缠论规则、前端、账号、策略或复权算法。

## 行为

- 原节点连接错误、超时、报文解码失败时，从当前节点起环形遍历整池；去重，每个请求最多一轮；换节点握手失败继续下一台。
- 使用同一命令对象重试，代码、市场、周期、起始偏移、条数、复权参数不变；不会把 QFQ 静默换成 NONE。
- 成功后继续使用当前节点，仅在业务解析成功后写 MAC 专属最佳节点配置；配置写入失败不会丢失已取得的数据。
- 合法空结果不当作异常；残缺 K 线头和声明记录数不足均明确报错并换源，不返回残缺历史作为成功结果。
- 全部失败返回中文 503，带 Retry-After: 5；逐节点具体错误留在日志及异常 attempts 中。
- 启动握手亦遍历全池。启动全部失败后保留客户端，后续请求可恢复；最后失败的节点恢复后会重连，避免卡在未连接状态。
- 整轮切换串行保护；异步心跳重连不取消/等待自身任务。只捕获连接与解码异常，程序错误不被吞掉。
