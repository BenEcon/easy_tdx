# DEA 容差独立对照（2026-10-03）

按用户认可的建议增加第四项独立研究对照，不替换严格版，不生成 BC、M1、结构买卖点或策略信号，不与完整 A／等价对照叠加。

## 口径

- 保留有效 A、价格严格突破、C 同色柱面积严格小于 A、DIF 段内极值严格改善、有效 ABC 全程双线同侧及 B 回拉要求。
- DEA 使用 A、C 各自整个比较段的极值，底背离取最低值、顶背离取最高值；不要求出现在价格极值当天。
- 新对照允许 DEA 严格改善、相等，或不利偏差不超过 5%。5% 是初始研究阈值，不代表已经验证的投资有效性。
- 顶背离不利偏差：`max(0, C峰值-A峰值)/abs(A峰值)`；底背离：`max(0, A谷值-C谷值)/abs(A谷值)`。
- `abs(A的DEA极值) <= 1e-9` 时禁用相对容差，仍可按严格改善通过；不添加绝对放宽量，不按显示精度判定。DIF 不使用容差。
- 进行中的 C 只显示暂时满足；C 变色结束后才显示结束复核通过。对照不记录或回填正式确认事件。

## 界面

在“背离／背驰 → 波段核验与规则对照 → 对应 ABC”下新增“面积缩小 ＋ DIF 改善 ＋ DEA 容差 5%”。沿用前端技能的低装饰折叠列表，显示研究范围、阈值、实际偏差、各自极值日期以及近零限制；默认规则和研究结果分开。
