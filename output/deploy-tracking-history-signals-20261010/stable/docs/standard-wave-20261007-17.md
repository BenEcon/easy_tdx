## 新标准

1. B 价格不限制；底部 C 最低 ≤ min(A 最低, B 最低)，顶部严格对称。沿用 1e-6 数值比较容差。
2. 比较 A 仍为最后一次双线进入目标零轴侧后的连续尾段；价格、面积、DIF、DEA 一律取同一个有效 A。
3. 有效 A、C 双线始终同侧；DEA 在完整有效 ABC 同侧。B 的 DIF 允许最多一个连续触轴／跨轴区间，最多 5 根；等于零也计入。两次区间即拒绝，不能累计拼接或截掉 B。
4. C 同色柱面积小于 A，C 的 DIF、DEA 各自段内极值都改善，B 内双线回拉；不是比较价格极值当天的线值。
5. C 进行中为候选；连续两根缩短仅初步确认；C 色柱结束、整段复核通过，才最终确认。M1 仍只能来源于最终确认的标准波段。

**用户已确认**：B 的 DIF 不设跨轴幅度上限，仅限一次、连续最多 5 根；触零计入，DEA 始终不触轴。顶底对称。
