## 最终确认口径

用户曾提出取消双线极值改善要求，随后明确修订为：C 段面积小于 A 段，且 C 段范围内 DIF、DEA 各自的极值相对 A 段范围内改善。本次以最后这条为准，已撤回中途的“仅参考”调整。

- 底背离：`min(DIF[C]) > min(DIF[A])` 且 `min(DEA[C]) > min(DEA[A])`。
- 顶背离：`max(DIF[C]) < max(DIF[A])` 且 `max(DEA[C]) < max(DEA[A])`。
- 两条线分别在各自完整比较范围内取极值，可以出现在不同 K 线上，不要求发生在股价极值当天。
- 同时满足 `0 < C 同色柱面积 < A 同色柱面积`。计算用原始精度，不按显示两位小数判定。
- 默认 A 仍为已确认的有效轴侧尾段；价格、面积及双线极值均在同一个有效 A 中计算。从有效 A 至 C 全程同侧、价格严格突破、B 回拉以及 C 变色结束后复核等条件不变。
- 最近局部极值双线背离、严格成笔、结构买卖点及高层级递归规则均不变。

## 新增网页功能

### 首次失效的证据

波段候选失效时保存独立 `failure_audit`，包含首次失效当时的 A/B/C 范围、检查结果与数值。候选最后一次通过的依据仍保留，并明确区分“最后通过”和“首次失效”，避免只看到先前成立的数值，却不知道后面为何失败。

零轴失败附首次异侧／触轴位置、值及数量；双线检查附 A/C 指标极值发生时点。主界面数字仍为两位小数，若两个不同值被舍入成相同数字，展开依据会补充六位或更高精度，说明计算未四舍五入。同价极值后移不再误称“出现新低／新高”。

### 三种研究对照

用户选择保留默认规则，增加对照，未授权改变默认的轴侧或价格门槛：

1. 仅完整 A：原色柱 A 不截取跨轴部分，其所有统计同步重新计算；B、C 仍全程同侧。
2. 仅允许等高／等低：保持有效 A，C 可达到或突破 A 价格极值。只使用原有 0.000001 数值误差，不引入“一分钱内都相等”。
3. 两项同时：完整 A 加允许价格相等。

三种对照均保留面积缩小、DIF/DEA 段内极值改善、B 回拉、完整色柱历史和完整数据要求。对照只显示截至当前回放位置的复核，不生成 BC、M1、结构买卖点或策略信号；未结束 C 即使通过也标为暂时满足，不回填确认。

沿用前端技能的低装饰、分层展开布局。默认展示状态与原因，三项对照可分别展开，支持窄屏换行。
