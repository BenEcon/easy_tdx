### 第二阶段：账户与 API 安全（进行中，未部署）

- 异步任务提交绑定账户，列表与结果只允许本人查询；管理员不自动取得他人任务。节点测速/切换仅管理员可用，限制配置节点白名单、超时、数量和并发。此前组合验证 110 项、节点与任务专项 13 项通过。
- 全部业务 HTTP 路由通过受保护路由组统一要求登录；初始化/登录/状态接口保留公开访问，账户修改原有独立权限不变。测试逐一请求当前 77 个非认证业务 HTTP 路由，检查匿名拒绝，不只抽样。
- 同源默认；跨域来源通过 `EASY_TDX_ALLOWED_ORIGINS` 显式配置，不允许通配符。写请求检查 Origin / Sec-Fetch-Site；API 请求体上限 8 MiB，认证请求 8 KiB，偏好请求 70 KiB（存储仍 64 KiB），无 Content-Length 的分块输入同样累计检查。
- WebSocket 握手验证会话与来源，校验证券代码，最多 32 个订阅标的、单条应用消息 4 KiB；撤销会话后停止推送。仍需补每用户连接数、消息频率和传输层帧大小限制，不能据此宣称资源保护已完整。
- 登录限频存于 SQLite，并在事务中预占：同账户 8 次/5 分钟、同对端 30 次/分钟、安装实例 200 次/分钟。跨进程共享，服务重启不清空；429 带 Retry-After；未知账户也进行密码摘要计算。限频键哈希，不保存原始对端或用户名；成功登录也计入配额。
- 首次初始化和最后管理员保留约束移入同一写事务；权限变更、密码修改与停用撤销旧会话；增加退出全部设备接口。账户创建、权限修改、密码修改和登录结果写入最多 10000 条审计记录，不包含密码、会话 token、请求体或原始 IP。审计查询 UI、节点变更审计等仍待补。
- 未知 API 路径不再回退到 SPA 的 HTML；真正静态资源异常不再全部掩盖为首页。
- 新增账户安全测试覆盖并发初始化、并发降级、持久化限频、并发预占、撤销会话与无敏感字段审计。账户安全/账户/任务/节点组合 32 项通过；API/账户/回测/雷达较广回归 131 项通过。请求安全专项初跑 10 项通过，1 项仅因预估路由数量大于 80 的断言失败（实际 77 个均通过），已改为当前实际下限并继续复测。
- 上述安全组合复测 43 项全部通过；部署来源、代理、Cookie、迁移检查和权限矩阵见 `docs/platform-security.md`。
- 真实浏览器（本地临时账户、模拟行情）验证首次创建、登录、退出、错误密码提示、手机重新登录；手机截图 `output/playwright/platform-security-login-mobile.png` 已人工检查。
- 浏览器回测发现并修复阶段一的兼容性遗漏：`period_end` 字符串被 `StrategyDataProxy` 当数值因子转换，产生 400。新增 `test_backtest_metadata_input.py` 三条测试先复现再修复（原始服务端帧、网页内联记录、自定义因子保留）。策略数值代理排除 `period_end` 和 `is_closed`，原始 DataFrame 的元信息与其他数值因子不删除。回测/雷达/区间组合 99 项和引擎/策略/组合 73 项通过。重启本机临时验收实例后，真实网页回测返回图表、评级和交易列表，截图 `output/playwright/platform-security-backtest-mobile.png`，390px 屏幕宽度与文档宽度均 390px。模拟数据仅用于交互验收，不用于金融结论。
