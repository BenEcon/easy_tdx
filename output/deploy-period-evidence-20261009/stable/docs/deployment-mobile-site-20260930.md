# 全站手机适配 · 2026-09-30

## 本轮改动

在第一轮手机导航和缠论适配基础上，按 frontend-skill、sidebar-dialog-ux 保留暗色风格、紧凑布局和原有桌面操作。

- 个股分析、组合回测、参数寻优：增加手机设置折叠，首次结果完成后收起设置；返回已有结果时优先显示结果。
- 结果对比改为手机纵向布局；策略库使用单列卡片，日期输入单列，长名称和结果摘要可换行。
- 对比、组合绩效、寻优排名和持仓明细增加独立横向滚动容器；成交记录保持可读列宽，数据表限定手机垂直占用。
- 技术指标库改用原生模态 dialog；手机不再隐藏参数与应用按钮，分类可横向滚动，参数步进使用更大的触控区域，支持 Escape、焦点限制及全屏中的弹窗。
- 全站手机弹窗跟随 visualViewport 高度和偏移；股票历史复用可见视口定位，避免软键盘遮挡和窗口越界。
- 净值、组合和对比图改用容器尺寸监听；滚动图例处理长名称，坐标轴保留标签空间，净值轴用万/亿缩写。提示框限制宽度，参数热力图调整边距及色标。
- F10 长文跟随页面滚动，保留局部表格横向滚动；提升手机按钮字号、输入字号、点击区域及详情展开区的可操作性。

未修改后端、缠论判定规则、交易算法和用户数据。
